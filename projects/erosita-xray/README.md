# eROSITA All-Sky X-ray Anomaly Scan

**Status:** Planned | **Paper:** TBD | **Target:** A&A

## Overview
First autoencoder anomaly detection on eROSITA X-ray data. 710K sources from the first all-sky X-ray survey since ROSAT (1990s). Completely different wavelength regime from DESI — highest novelty potential.

## Goals
1. Download eROSITA DR1 catalog
2. Train X-ray spectral autoencoder
3. Score all 710K sources
4. Cross-match with DESI anomalies (multi-messenger)
5. Identify unusual X-ray sources
