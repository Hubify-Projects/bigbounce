System Architecture

The research platform is built on five layers: compute (GPUs), data (archives + storage), AI models (autoencoders + classifiers), platform (orchestration + UI), and the human loop (researcher + multi-model review).

The Pipeline Pattern (repeatable per survey):
Public Archive (DESI, SDSS, Planck, etc.)
  → Download + preprocess (survey-specific FITS handling)
    → GPU inference (autoencoder / classifier / time-series)
      → Anomaly catalog (Parquet, scored + classified)
        → Cross-reference (SIMBAD, NED, Gaia, AllWISE, Milliquas, SDSS)
          → Interactive explorer (web UI + Convex real-time DB)
            → Human review + multi-model analysis
              → Paper + HuggingFace data release

Data Formats

Input: FITS (spectra, images, CMB maps), CSV, JSON

Processing: PyTorch tensors, numpy arrays

Output: Parquet (columnar, zstd compressed, ~367MB per 500K-row batch), JSON (metadata, checkpoints)

Catalogs: 45-173 columns per row including anomaly scores, 128-dim latent vectors, pipeline redshifts, photometry, morphology, derived classifications

Layer 3: AI Models

BigAE — Spectral Autoencoder

Architecture: 496 → 512 → 256 → 128 → 128 (latent) → 128 → 256 → 512 → 496

Parameters: ~660K

Training: 47K DESI spectra, MSE loss, dropout 0.1-0.15

Inference: 896 spectra/sec (GPU), ~24h for 17.65M

Anomaly metric: Reconstruction error (MSE), per-band (B/R/Z)

HuggingFace: bamfai/desi-spectral-anomaly-detector

Chirality CNN v2

Architecture: ResNet-based, 3-class (CW/CCW/NOT_SPIRAL)

Accuracy: 93.7%

Bias tests: 8/8 passed (rotation, flip, color, crop, etc.)

Equivariant CW fraction: 0.5012 (benchmark subset); 0.4974 (full equivariant catalog)

HuggingFace: bamfai/galaxy-chirality-v2

CMB Patch Autoencoder

Architecture: Conv autoencoder, 128-dim latent

Parameters: ~1.1M

Training: Planck SMICA patches (gnomonic projection)

Status: Prototype, 42 anomalous patches found

MCMC Infrastructure

Cobaya 3.6.1 + CAMB 1.6.5 for cosmological parameter estimation

Chains: 309,789 frozen samples across 3 ΔNeff dataset combinations (Full Tension, Planck+BAO+SN, Planck Only). Zero free w0-wa samples in this program (Paper 1 §VII.H).

Key results: ΔNeff = −0.020 ± 0.169, H0 = 67.68 (standard ΛCDM). Earlier “P(quintom-B) = 98%” was fire-#21 confabulation, retracted fire #25 (2026-04-18).

Layer 5: Human-in-the-Loop

The Houston Approach

The critical differentiator is not the technology — it's the research methodology. Key principles:

  • Never accept "publish the negative result" — failures narrow the search space; keep looking for positive discoveries
  • Always do the harder thing — don't add 11 columns when you could add 45; don't scan 200K spectra when you could scan 18M
  • Parallelize everything — run multiple research tracks simultaneously; don't wait for one to finish before starting the next
  • Back up everywhere — data loss is the only unrecoverable failure
  • Push past conservative AI recommendations — when Claude says "this is ready to publish," ask "what else could we add?"
  • Bounce-model agnostic — when one model fails, pivot to another; the goal is proving bounce beats inflation, not defending one specific mechanism
  • Multi-model cross-validation — use Claude, ChatGPT, and Gemini as complementary reviewers; synthesize the strongest insights from each
  • Relentless optimism — 14 barriers closed? Good, that's 14 things we don't need to worry about anymore. What paths remain open?
