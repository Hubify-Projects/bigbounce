Data Explorer

Interactive reference for the MCMC chains and external datasets used to constrain the spin-torsion cosmology model. All chains sample \(\Lambda\)CDM + \(N_{\rm eff}\) with Cobaya, using CAMB as the Boltzmann solver. Designed for anyone who wants to understand, verify, or reproduce the analysis.

Chain File Format

Each chain is stored as a plain-text file following the Cobaya/CosmoMC convention.

Format specification

Delimiter Space-separated (multiple spaces between columns)
Header Row 1, prefixed with #. Column names follow, space-separated.
Columns 33–46 depending on dataset (planck_only: 33, planck_bao: 42, planck_bao_sn: 42, full_tension: 46)
Weight column Column 1 (weight). Integer multiplicity — each row represents weight accepted MCMC steps at that point.
File naming spin_torsion.1.txt inside each chain directory
Encoding ASCII, Unix line endings

Directory structure

reproducibility/cosmology/paper1_clean_restart_sync/chains/dneff/
  full_tension/
    chain_01/  spin_torsion.1.txt  cobaya_config.yaml  spin_torsion.input.yaml
    chain_02/  ...
    ...
    chain_06/  ...
  planck_bao_sn/
    chain_01/ ... chain_06/
  planck_bao/
    chain_01/ ... chain_06/
  planck_only/
    chain_01/ ... chain_06/

Loading in Python

import numpy as np

# Load a single chain
data = np.loadtxt("spin_torsion.1.txt")
weights = data[:, 0].astype(int)
H0 = data[:, 20]  # column index for H0 (0-based, after weight)

# Or use GetDist (recommended)
from getdist import MCSamples, loadMCSamples
samples = loadMCSamples("spin_torsion")
print(samples.getTable().tableTex())

Download: Chain files are available in the GitHub repository under reproducibility/cosmology/paper1_clean_restart_sync/chains/dneff/. Cobaya input YAML files (spin_torsion.input.yaml) are included alongside each chain for full reproducibility.
