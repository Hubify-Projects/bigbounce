How Review Works

  1. Click a pipeline above to open its review dashboard
  2. Each object has a sky image from Legacy Survey, AI notes, and metadata
  3. Click any row to expand the detail panel with the image and review form
  4. Assign your label: INTERESTING / ARTIFACT / KNOWN_TYPE / NEEDS_SPECTRUM / CONFIRMED
  5. Add your notes in the comment box
  6. Reviews are saved to your browser (localStorage) and can be exported as JSON

Storage: All review data persists in your browser’s localStorage. Use the Export button on each pipeline page to save a JSON backup. No server-side database is required for the review workflow.
