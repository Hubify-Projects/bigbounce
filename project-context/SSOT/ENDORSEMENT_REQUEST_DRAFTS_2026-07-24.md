travelling and you lose a week finding out. Two asks in flight halves the
expected wait and costs nothing. Two endorsers acting on the same code is
harmless: the second simply sees the endorsement is already in place. Do **not**
tell anyone they are the only person being asked, and do not imply exclusivity.

ask is still outstanding for the same code — send that person a short note
saying the code has cleared and they can ignore it. Costs 30 seconds, and is
the difference between a good impression and a mildly annoyed one.
