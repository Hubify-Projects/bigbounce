This is a referee report for the manuscript "The Largest Test of a Preferred Galaxy-Spin Axis..." submitted to ApJS. 

The paper presents a highly rigorous, well-powered observational test of a specific cosmological prediction (the rotating-black-hole-universe preferred spin axis) using an 8.47-million-galaxy chirality catalog. The statistical methodology is exceptionally careful, particularly the distinction between fixed-occupancy label-randomization nulls and binomial nulls, and the explicit acknowledgment of the missing morphology transfer function (Assumption 2) preventing a direct physical deprojected-spin bound. The mathematical derivations and reported statistics are internally consistent and reproducible from the text.

However, there are a few critical manuscript-preparation issues—specifically regarding abstract-to-body consistency, undefined dataset references, and residual version-history language—that must be resolved before publication.

### ESSENTIAL (Must be fixed before acceptance)

**1. P4P-E1: Abstract-Last Drift on "Upper Limit"**
*   **Location:** Abstract, page 1; Section 3, page 5.
*   **Problem:** The abstract claims "a coverage-calibrated observed-label 95% sensitivity upper limit $A_{95}^{\text{obs}} \simeq 0.98\%$". However, Section 3 explicitly warns the reader: "It is not itself a confidence-level bound on the measured value... A genuine 95% confidence-level upper limit requires the complementary Neyman inversion... gives $A_{95}^{\text{CL}} \simeq 0.75\%$". The abstract conflates the detection-power threshold ($A_{95}^{\text{obs}}$) with an upper limit, completely omitting the actual Neyman 95% CL limit derived in the body.
*   **Required Fix:** Update the abstract to either report the genuine Neyman limit ($A_{95}^{\text{CL}} \simeq 0.75\%$) as the upper limit, or correctly label $A_{95}^{\text{obs}}$ as a "detection-power threshold" or "sensitivity floor" while removing the phrase "upper limit" for that specific value.

**2. P4P-E2: Standalone-Reader Failure (Undefined Dataset)**
*   **Location:** Section 4, page 6, line 381.
*   **Problem:** The text states the void catalog is "intersected with the DR1 companion of the catalog in Sec. 2." Section 2 describes the DESI Legacy DR8 catalog but contains absolutely no mention of a "DR1 companion", how it was constructed, or what spectroscopic/photometric data it relies on. The reader cannot evaluate this intersection because the target dataset is undefined.
*   **Required Fix:** Explicitly define the "DR1 companion" in Section 2 or at the start of Section 4. Provide the necessary context (e.g., is this a DESI spectroscopic DR1 cross-match?) and a citation or construction summary so the paper is self-contained.

**3. P4P-E3: Residual Version-History Language**
*   **Location:** Table 4 caption, page 4.
*   **Problem:** The caption states "...the map-level low-$\ell$ real-$Y_{\ell m}$ regression in the archived release supersedes it...". The word "supersedes" and the framing of one test replacing another from an earlier draft/release is internal review-log/version-history prose that does not belong in the final published manuscript.
*   **Required Fix:** Remove the version-history framing. State the methodological justification for the current test directly (e.g., "We utilize a map-level low-$\ell$ real-$Y_{\ell m}$ regression because a linear Pearson correlation is inappropriate for the circular RA coordinate...").
