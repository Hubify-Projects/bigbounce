## Reviewer 1 — ChatGPT (REJECT)

### BLOCKERS (9)

#### B1. Reproducibility package not referee-verifiable
**Location:** Sec. IX, PDF p. 48–49; extracted lines 5137–5154
**Issue:** Paper claims pinned tag `paper4-v1.0.145` but PDF is v1.0.149. Review package did not include .tex source or local JSON/NPY/FITS/mask artifacts.
**Proposed fix:** Provide one immutable v1.0.149 (now v1.0.151) referee archive with PDF + .tex + bibliography + scripts + masks + generated figures + JSON/NPY/FITS artifacts + MC seeds + null distributions + SHA-256 manifest + exact environment.

#### B2. ~18σ formal-exclusion claim not publishable as written
**Location:** Sec. IV.D, PDF p. 25–26; extracted lines 2440–2565
**Issue:** Block bootstrap with Nboot=1000 cannot validate 18σ tail. NSIDE=8 block scale not stress-tested. Model is WLS+bootstrap scale, not fully specified spatial likelihood. Extended 24-template model not given block-bootstrap σ.
**Proposed fix:** Downgrade "∼18σ formal exclusion" to "strongly disfavoured under the adopted template model." Add block-size sensitivity, spatial jackknife, leave-one-footprint-out, posterior predictive maps, formal covariance.

#### B3. Mask hierarchy declared after results, not preregistered
**Location:** Sec. III.A, PDF p. 6; extracted lines 497–512; Sec. VI.F, extracted lines 4464–4473
**Issue:** Hierarchy declared, not preregistered, fixed after first catalogue results. Later text calls it "pre-specified" — contradiction. Inference rule "either consistent with null suffices" not acceptable when +3.64σ canonical exists.
**Proposed fix:** Formal mask-family inference OR preregistered-style frozen analysis replication. Conclusion must survive the declared family of masks, not only the selected primary mask.

#### B4. Canonical-mask residual not closed at systematics-likelihood level
**Location:** Abstract; Sec. IV.C–D; extracted lines 31–55, 1993–2407, 2440–2565
**Issue:** Residual +3.64σ per-pixel, +3.80σ density-stratified, only ~12% explained by post-MASTER monopole-only leakage. Present WLS basis does not include depth/PSF/extinction/morphology templates.
**Proposed fix:** Add full depth/PSF/extinction/morphology/leg/confidence template model. Publish residual C1 after nuisance marginalization.

#### B5. Null models mixed as if σ values were commensurable
**Location:** Table II, Table VI, Sec. IV.C–D, Appendix VIII
**Issue:** Per-pixel shuffles + MASTER label-shuffle MC + binomial monopole-only + density-stratified + sky rotations + hemisphere max-stat MC + analytic Bonferroni/BH + WLS/template fits all mixed into one σ narrative.
**Proposed fix:** Define ONE primary cosmological null and ONE primary systematics-preserving null. Other results labelled diagnostics, not merged into "σ" story.

#### B6. Sensitivity claims internally inconsistent
**Location:** Sec. III.A (542–563); Sec. VI.C (4069); Sec. IV.D (2440–2455)
**Issue:** Paper alternates among Fisher floor ∼0.29%, HC-subsample empirical threshold 0.75%, classifier-diluted true-amplitude ∼1.19%, full-catalog injection <0.50%. Elsewhere text says full-catalog injection sweep is deferred.
**Proposed fix:** Choose ONE headline sensitivity number (empirical, systematics-inclusive, corresponding to exact primary estimator/sample). Other numbers in single amplitude-convention table.

#### B7. Classifier uncertainty not propagated into cosmological covariance
**Location:** Sec. III.E; Sec. IX (5155–5161); D4 hold-out discussion
**Issue:** 0.26% uniform CW-bias residual + 69.91% GZ1 CW/CCW agreement (κ=0.40) + 21% D4 argmax instability on borderline objects. Labels not ground-truth, yet cosmological covariance does not include classifier calibration / TTA uncertainty.
**Proposed fix:** Use soft probabilities in headline estimators. Propagate classifier calibration + pseudo-label bias + morphology-coupled error + D4/TTA instability into covariance.

#### B8. Shamir comparison sample-size ambiguity
**Location:** Introduction and Sec. V.A; extracted lines 263–270, 3398–3403
**Issue:** Sec. V.A still uses ~200,000 post-Ganalyzer spiral number to claim ~2.5× larger sample, conflicting with public ~1.3M scale.
**Proposed fix:** Cite exact Shamir 2022 table/selection yielding ~2×10^5 post-Ganalyzer spirals OR remove 2.5× comparator. Keep comparison as "not like-for-like" throughout.

#### B9. Manuscript not journal-clean
**Location:** Throughout; examples at extracted lines 33, 505, 539, 1841, 2483–2556, 4462
**Issue:** "canonical canonical-mask", "legacy +1.85σ legacy", "after the an earlier external review", "queued for the next post-submission revision", all-caps "FORMALLY EXCLUDED", "ChatGPT M3", pod/provenance language, malformed refs like "Sec. VI G 0 a".
**Proposed fix:** Strip internal audit/version-control prose. Keep only scientific methods + standard reproducibility statement + short AI-use disclosure if journal requires.
