VERDICT: MINOR REVISIONS

ISSUES:

[MAJOR] §V B (and abstract): The DESIVAST-anchored path is explicitly designated post-hoc as the "exploratory primary" after data inspection ("no timestamped analysis plan predates the data"); while the uniform Bonferroni-5 null across all five void definitions is robust and the garden-of-forking-paths budget is disclosed, leading with a single designated row as the headline "new empirical constraint" weakens the claim without pre-registration (DR2 commitment noted but does not retroactively fix DR1).
[MAJOR] Abstract, §VIII (systematic envelope + de-attenuation), and Table XI: The quoted de-attenuated physical-chirality bound ≈2.26 pp (from observed ≈0.9 pp envelope divided by 2a−1 ≃0.40 at 69.91% GZ1 accuracy floor, κ=0.40) treats the attenuation factor as directly transferable to the DESI-trained equivariant ViT without an independent held-out validation set or explicit test that misclassification errors are symmetric and environment-uncorrelated; this is the quantity "model-builders should use," so the justification must be tightened or the bound presented strictly as classifier-labelled.
[MINOR] §VI A, §XI, and §XIII (T-Web secondary path): The ~2.1σ filament bright-vs-dark sign-flip (and analogous cluster pattern) is attributed to BGS selection-function + imaging-leg systematics, but the paper acknowledges residual ambiguity, lack of end-to-end injection-recovery mock, and non-orthogonality (χ²=4933, Cramér’s V=0.078); while leakage into the primary volume-limited DESIVAST contrast is shown to be <<0.01 pp, the secondary path still requires either quantitative propagation or clearer flagging that it does not undermine the overall systematics envelope.
[MINOR] §I (Introduction) and abstract: The statement "No published bounce or inflation model currently predicts an environment-conditional chirality signature at this scale" is presented without supporting literature citations or search summary; this is a substantive claim that any such model "must satisfy" the new bound and therefore needs explicit grounding.
[MINOR] §IV A, §VIII, and reproducibility statements: The T-Web and DESIVAST pipelines rely on committed artifacts, deterministic seeds, and companion data repo references (plus Paper IV placeholder arXiv); for PRD archival standards, all exact configs, grid resolutions, mask-dilation iterations, and analysis drivers must be permanently deposited with DOIs and version pins so the 256³ CIC + Gaussian smoothing + eigenvalue classification chain is independently reproducible.

The central claim (environment-independent spiral chirality at the ≳25 Mpc/h scale, with honest ≈2.26 pp de-attenuated physical upper bound from a clean null across multiple void definitions) is supported by the data, permutation tests, and systematics bounding.
