Strong, unusually transparent null-result paper. I do not see a blocker requiring major scientific rework, but several claims need tightening before acceptance.

2. BLOCKERS
None.

3. MAJORS

1. Scope of headline should be narrowed. The strongest result is a DESIVAST void/non-void null, not a general four-class "environment dependence" result. The abstract/title should avoid implying full cosmic-web environmental coverage is equally primary.

2. Post-hoc primary choice needs sharper wording. The paper declares the DESIVAST primary path post-hoc and handles multiplicity transparently, but the abstract still reads more definitive than a post-hoc primary designation warrants.

3. T-Web selection-function instability is large. The selection-corrected rebuild radically changes environment populations, even if chirality remains null. Should be framed as evidence that T-Web labels are diagnostic/secondary only, not as a coequal environment classifier.

4. RSD limitation remains real. The paper correctly flags fixed-redshift-space classification, but the conclusion should repeat that the null is redshift-space and fixed-catalog/void-geometry conditioned.
