## Sourcing the N_gal mystery

R30 left this OPEN. R31 traced it:

- `master_power_spectrum.json` (committed to the repo, written by the on-pod NaMaster
  driver) records: `n_galaxies = 5,547,858`, `f_sky = 0.6588`, `n_unmasked_pixels = 32,384`,
  `C1_noise = 1.2577e-6`.
- Arithmetic check on the noise term: `4π × 0.5552 / 5,547,858 = 1.258 × 10⁻⁶`, matching
  the JSON to 4 sig figs. So the pipeline used an **occupancy-weighted** `f_sky ≈ 0.555`
  (close to the paper's stated 0.56), **not** the geometric 0.46 nor the pixelized 0.659.
- 5,547,858 ≠ 8,474,531 (full catalog) and ≠ 3,321,795 (spirals only). The intermediate
  value is consistent with: **galaxies of any class (CW, CCW, NS) that fall inside the
  unmasked pixels** at `N_side=64`. The full-catalog rows excluded are those whose pixel
  failed the apodized mask threshold; the spiral-only number excludes NS objects that
  contribute to the per-pixel total used to normalize the asymmetry field.
- No on-disk MASTER source script (the run was on a remote pod), so the field-definition
  detail is inferred from the JSON contents and the matching shot-noise arithmetic, not
  from re-reading the driver.

**Verdict on R30's flag**: the shot-noise formula `C_1^noise = 4π·f_sky/N_gal` is the
correct partial-sky Poisson white noise for a number-density tracer (Hivon 2002 §3,
NaMaster docs `nmt.NmtField`). Whether the relevant `N` is `N_gal=5.55M` or
`N_spiral=3.32M` depends on which normalization the per-pixel field uses. With
`N_spiral`, the noise rises by 1.67× to ~2.1×10⁻⁶ and `C_1^signal` flips sign, but the
post-MASTER significance is **−0.12σ either way** (the deconvolution does not depend on
the cosmetic shot-noise subtraction). So the conclusion is robust.

## Findings

### MAJOR — N_gal = 5,547,858 lacked provenance and disambiguation [FIXED]

**Location:** §V.A "Dipole Analysis", line 815 (pre-fix)

**Problem:** The text introduced `N_gal = 5,547,858` with the phrase "galaxies with valid
chirality classifications" — but this number does not match any of the headline catalog
counts (8,474,531 total / 3,321,795 spirals / 5,152,736 NS), and was therefore unsourced
to a reader. R30 explicitly flagged this as an open question. R30 also raised the
follow-up: would using `N_spiral` flip the sign of `C_1^signal`?

**Fix:** Added a footnote at the `N_gal` definition that:
1. Cites the exact provenance (`master_power_spectrum.json` `n_galaxies` field).
2. Explains why 5.55M sits between the full 8.47M and the spiral 3.32M (NaMaster
   discards pixels failing the apodized mask; the per-pixel total includes NS objects
   for asymmetry normalization).
3. Computes the alternative-`N` case (`N_spiral`) explicitly: `C_1^noise → 2.1e-6`,
   `C_1^signal` flips sign, but post-MASTER significance is unchanged at −0.12σ.

This closes R30's open question and pre-empts the same review comment from a future
referee.

### MINOR — "Fitted dipole amplitude is 0.43σ" conflates amplitude with significance [FIXED]

**Location:** §V.A "Simple dipole", line 731 (pre-fix)

**Problem:** "the fitted dipole amplitude is $0.43\sigma$ ($p=0.33$)" — `0.43σ` is a
significance value (deviation from MC null mean in units of MC null std), not an
amplitude. An amplitude has units (here, fractional CW excess); the actual fitted
amplitude on the post-TTA Catalog C is small enough that the paper appropriately
declines to publish it as a number, but the prose label "amplitude" was wrong.

**Fix:** Changed "the fitted dipole amplitude is $0.43\sigma$" to "the fitted dipole
has significance $0.43\sigma$".

## Verified clean (no new finding)

- **Shot-noise formula** `C_1^noise = 4π·f_sky / N_gal` matches Hivon 2002 partial-sky
  Poisson white noise for a number-density tracer; arithmetic with `f_sky=0.56` and
  `N_gal=5,547,858` reproduces `1.26 × 10⁻⁶` to the digit.
- **f_sky values**: 0.46 (geometric DESI Legacy footprint), 0.659 (effective at
  pixelized `N_side=64`), 0.56 (occupancy-weighted, used in shot-noise) — all three
  values appear with explicit context, no ambiguity.
- **Cross-paper N totals**: Paper 1 §VIII.A and Paper 1 falsifiability table both cite
  the 8,474,531 total; matches Paper 4 abstract and §IV.A.
- **Equivariance demo figure** caption (`fig_equivariance_demo.png`, line 421-432)
  describes the TTA procedure adequately; train/test split is reported separately in
  §II.B (line 237: "26,636 images, split 80/20 ... stratified class balance").
- **ℓ_max choice**: `N_side=64`, `ℓ_max=5` for the published table is well below the
  resolution limit (`3·N_side ≈ 192`) and well above the shot-noise reach (~1°
  pixels, 171 galaxies per pixel on average). Conservative and appropriate.
- **Multipole table values** (Table IV: ℓ=1, C×10⁶=3.82, σ=2.75) are the raw `anafast`
  pseudo-C_ℓ, consistent with the post-MASTER `C_1^meas = 1.49×10⁻⁶` (different
  estimators, different values; both reported with the right label).
- **Dipole D=0.0019 from R30's note**: traced to `outputs/dipole/summary.json`
  `dipole.amplitude` field; this is the **pre-TTA** value (raw Catalog A). The paper
  correctly publishes only the post-TTA Catalog C significance (0.43σ) as the
  headline result, with the raw 94.6σ artifact reported as the cautionary
  systematic. No new fix needed.
