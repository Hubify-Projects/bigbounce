*   **Specific Problem:** There is a mathematical typo in the Fierz matrix $F_c$ printed in Eq. (C1) that breaks the explicitly stated identity $F_c^2 = 1$. The (1,3) element of the matrix is printed as `1`. If we compute the (1,1) element of $F_c^2$ using the printed matrix, we get $(F_c^2)_{11} = \frac{1}{16} [1(1) + 1(4) + 1(12) + (-1)(-4) + 1(1)] = \frac{22}{16} = 1.375 \neq 1$.
