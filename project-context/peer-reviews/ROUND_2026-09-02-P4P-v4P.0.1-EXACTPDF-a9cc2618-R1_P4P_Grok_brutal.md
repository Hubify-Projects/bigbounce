**P4P-E1** (ESSENTIAL)  
Section 1 / p. 1, lines 63–64: “(see project-context/PORTFOLIO.DECISION.2026-09-02.md, Track C1 Addendum)”.  
Internal bookkeeping path appears in the published text.  
**Fix:** Remove all internal repository / decision-log strings before resubmission.

**P4P-E2** (ESSENTIAL)  
Section 2 / p. 2 and throughout: “Full architecture, training-data provenance, bias-hardening audit … are described in the archived release paper (15) and are not reproduced here.”  
ApJS catalog standard requires the methods, QC flags, and calibration pipeline to be self-contained or explicitly tabulated. The paper is not usable without opening the companion.  
**Fix:** Either expand to include the minimal reproducible description or withdraw as a catalog paper.

**P4P-E3** (ESSENTIAL)  
Abstract, line 13: “N_support = 887,472 of 890,069 quality-controlled rows”.  
Body (p. 2) states 890,069 rows after the raw_flip_qc_unsafe cut, then 887,472 after HEALPix occupancy cut. The two numbers are not identical; the abstract mixes supported-pixel and quality-controlled totals without clarification.  
**Fix:** State exact numerator/denominator definitions in both abstract and body.

**P4P-E4** (ESSENTIAL)  
Abstract + Sec. 5: The 0.98 % sensitivity floor (Eq. 1) is presented as excluding literature amplitudes, yet the paper explicitly states the closure A_pred ≈ η is adopted “for lack of a quantitative prediction in the cited Poplawski papers”. No numerical mapping from the torsion model to an observable dipole amplitude is supplied.  
**Fix:** Either derive or cite a falsifiable amplitude from the model or rephrase the exclusion as “under the minimal closure we adopt”.

**P4P-M1** (MAJOR)  
Sec. 3, p. 2: dipole fit uses healpy.fit_dipole on supported pixels only; no covariance or mask-induced bias test is shown. The quoted one-sided p = 0.238 is therefore conditional on an unvalidated mask.  
**Fix:** Add mask-robustness test or qualify the p-value.

**P4P-M2** (MAJOR)  
Fig. 2 and Sec. 4: four-class T-Web result is shown, yet the primary void/non-void contrast (Eq. 2) uses a binary VoidFinder definition. No cross-tabulation or consistency metric between the two classifications is provided.  
**Fix:** Demonstrate that the null result is insensitive to the choice of web classifier.

**P4P-M3** (MAJOR)  
Table 1 ratios are computed with a 1/√N scaling ansatz calibrated only to this catalog’s own A_95^obs. The table therefore does not constitute an independent re-analysis of the earlier pipelines.  
**Fix:** Either re-analyze the public earlier catalogs with the present estimator or label the ratios as “illustrative only”.

**P4P-N1** (MINOR)  
Header date “DRAFT VERSION SEPTEMBER 2, 2026” and “Dated: September 2, 2026” appear on p. 1.  
**Fix:** Update to actual submission date.

**P4P-N2** (MINOR)  
Fig. 1 caption states “No coherent large-scale structure is visually apparent” while the color bar spans ±0.08. No quantitative test of residual quadrupole or higher multipoles is shown.  
**Fix:** Add a one-sentence statement that the dipole-only model is an adequate fit.

**P4P-N3** (NIT)  
Several sentences repeat the phrase “the cited mechanism papers give only a qualitative alignment tendency”. Minor stylistic redundancy.

**Summary recommendation**  
**REJECT**

The manuscript cannot be evaluated as a standalone ApJS catalog paper. Core validation, classifier provenance, and the quantitative link between the Poplawski model and an observable dipole amplitude are all deferred to external documents. In addition, an internal repository path remains in the text and the abstract mixes sample definitions. These are first-read barriers for the venue.
