3. MAJORS
Primary/secondary hierarchy is defensible but post-hoc. The manuscript declares the DESIVAST path primary only after multiple environment classifiers and stratifications were explored. The authors disclose this clearly, and the five DESIVAST estimators are null, but the abstract/headline should avoid language implying an a priori analysis plan.
T-Web path is heavily selection/RSD/systematics conditioned. The T-Web environment labels are affected by radial selection, survey shell geometry, target-program non-orthogonality, and redshift-space classification. The paper handles these well, but the conclusions should consistently foreground DESIVAST as the actual load-bearing result and phrase T-Web as diagnostic.
Some robustness language is stronger than the evidence. ASTRA EDR has only 25,186 overlap spirals and poor per-galaxy agreement with T-Web; Tempel is SDSS DR10/richness-based; external T-Web comparison is volume-fraction only. These are useful consistency checks, not strong independent validations.
4. MINORS
The abstract is too dense and contains many caveats inline; it would be clearer to separate “primary result,” “secondary diagnostics,” and “limitations.”
The “largest matched-sample environmental-dependence test” wording is appropriately qualified later, but should be similarly qualified wherever it appears.

The toy EFT appendix is useful but speculative; keep it explicitly non-load-bearing and avoid implying a quantitative coupling constraint.
The bright/dark residual around ~2σ should remain described as diagnostic only, not evidence for astrophysical structure.
