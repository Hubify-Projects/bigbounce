### DP4-01: Shamir factor-of-2 mislabel/double-count
- **class:** CLOSED-BY-EDIT (v1.0.231, propagated v1.0.232)
- Paper took Shamir's 1.7%–4.0% asymmetry, mislabelled it an `f_CW`-deviation and doubled it via `A_p=2(f_CW−½)` to `A_ref=0.034`, propagating into `z≈−18`, "7–18×" tension, and the WLS exclusion.
- REAL ERROR, FIXED. Algebra: `A≡(N_cw−N_ccw)/(N_cw+N_ccw)=2f_cw−1≡A_p`, so Shamir's 1.7% *is* `A_ref=0.017` without rescaling (source: reproduction arXiv:2410.15269 Table 1; Shamir 2020 arXiv:2007.16116). Corrected: A_ref 0.034→0.017, z −18.1→−7.64, tension 7–18×→3.7–8.8×, naive-WLS z −264.5→−112. Explicit source-cited derivation sentence added at abstract (tex L624), parity, conclusions, Appendix-D. Convergent MAJOR across EXT ChatGPT CG-9, INT Claude, INT OpenAI-9, INT Grok-a, EXT Grok-4.
- **fingerprint:** shamir, factor-of-2, A_ref, 0.034, 0.017, double-count, asymmetry, f_CW
