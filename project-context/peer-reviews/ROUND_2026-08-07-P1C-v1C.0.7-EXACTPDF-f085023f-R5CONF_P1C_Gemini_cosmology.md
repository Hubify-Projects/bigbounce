This is a referee report for the manuscript "A Structural No-Go Survey of Minimal Spin-Torsion Routes to Dark Energy and Bounce Phenomenology" submitted to Classical and Quantum Gravity (CQG) / Physical Review D. 

The manuscript presents a comprehensive, highly rigorous structural survey of the minimal Einstein-Cartan-Holst (ECH) framework, evaluating its viability as a source of late-time dark energy. The author systematically catalogs 13 mechanism-class constraints and provides explicit amplitude-budget closures for historical quantum routes, alongside a formal operator-basis argument. 

The theoretical physics and EFT power-counting in this paper are exceptionally solid. The author correctly applies single-scale Naive Dimensional Analysis (NDA) to the ECH field content, rigorously separating intrinsic parity-odd Lagrangian terms from parity-violating background effects (a distinction often muddled in the literature). The mathematical cross-checks, dimensional consistency, and abstract-to-body fidelity are outstanding. 

However, there are a few critical issues regarding data provenance (relying on a transient GitHub commit rather than a permanent DOI) and a typographical error in a load-bearing matrix equation that must be corrected before publication.

### Findings

**1. ESSENTIAL: Missing DOI Preparation and Version-History Prose**
*   **Location:** Data and Code Availability, page 13.
*   **Problem:** The manuscript relies on a GitHub commit hash (`9b92721d5d7e1`) for the August 2026 verification scripts, explicitly stating they are not in the Zenodo deposit. Furthermore, the text contains internal review-log/version-history prose: *"whereas the 2026-08-05 adjudication artifacts listed above post-date that deposit and are available at the pinned repository commit only, not within the Zenodo deposit."* GitHub is not a permanent archival repository. 
*   **Required Fix:** Update the Zenodo deposit (or create a new one) to include the `2026_08_05` scripts so that all load-bearing computational artifacts are backed by a frozen-release DOI. Remove the internal version-history prose explaining the discrepancy.

**2. MAJOR: Typographical Error in Load-Bearing Fierz Matrix**
*   **Location:** Appendix C, page 16, Eq. (C1).
*   **Problem:** The $5 \times 5$ Fierz matrix $F_c$ is printed with a $1$ in the $(1,3)$ position (first row, third column). The text explicitly claims that $F_c^2 = 1$. However, with a $1$ in the $(1,3)$ position, the dot product of Row 1 and Column 1 yields $22/16 \neq 1$, and Row 1 with Column 3 yields $-1/2 \neq 0$. The standard c-number Fierz matrix requires this element to be $1/2$. (Note: The fourth row, which is the axial source used for the actual derivation in Eq. C2, is printed correctly, so the physics conclusion of the lemma remains intact, but the matrix itself is mathematically incorrect as printed).
*   **Required Fix:** Correct the $(1,3)$ element of the $F_c$ matrix in Eq. (C1) from $1$ to $1/2$. 

**3. MINOR: Internal Version Tag in Header**
*   **Location:** Page 1, under the author's name.
*   **Problem:** The date line reads: `(Dated: August 6, 2026 (v1C.0.7))`.
*   **Required Fix:** Remove the internal version bookkeeping tag `(v1C.0.7)` for the final journal publication.

**4. NIT: Formatting of Matrix Fractions**
*   **Location:** Appendix C, page 16, Eq. (C1).
*   **Problem:** The fraction $1/2$ in the fifth row of the matrix is written with a slash, while the rest of the matrix uses integers. 
*   **Required Fix:** For typographical consistency in PRD/CQG formatting, consider factoring out the $1/2$ or writing it as a vertical fraction to match the visual weight of the surrounding matrix elements.
