### Claude leg

**C1 [MAJOR] — Labels not reproducible + conflicting internal training records (26,616 vs 26,626; 826 vs 846; 93.6878% vs 92.10%).**
Verdict: **ALREADY-TRACKED-GATE** (training-realization/provenance).
The conflict is disclosed verbatim in three loci: Abstract §1 (tex L765), training-labels §2.2 (L809: "committed BENCHMARK_REPORT.md gives 26,626 total rows and 846 CE non-spirals, while the committed Hugging Face README reports 92.10%"), and Table 12 `tab:training_provenance` (L1447–1461: audit 21,293/5,323/26,616 vs benchmark 846/26,626 vs README 92.10% vs audit 93.6878%; caption L1450 "Conflicting historical training-data records"; L1461 "Exact object/split manifest — not retained"). The paper explicitly frames the table as "a conflict disclosure, not an exact replay manifest." Claude's ask (reconcile to a single authoritative manifest or re-train with retained seed/split) is precisely the standing training-provenance gate. Not new.

**C2 [MAJOR] — No overlap-free independent label-reliability characterization (GZ1 training rows not removable; object IDs not retained).**
Verdict: **ALREADY-TRACKED-GATE** (independent-classifier-validation).
Disclosed at §6.1 (L1495: "does not contain an object-level anti-join against the 6,637 GZ1 training rows … must therefore be treated as overlap-contaminated rather than independent"), §2.2 (L809: "no retained object-ID manifest establishes exclusion of the 6,637 GZ1 training rows"), stratified-confusion §6 (L1511, L1528: "the historical training overlap was not removed from the GZ1 agreement calculation"), and Appendix (L1647). The 69.91%/κ=0.40 numbers are explicitly labeled "descriptive … not an independent validation metric." This is the tracked independent-validation gate. Not new.

**C3 [MAJOR] — Null is estimator-conditional; joint covariance open.**
Verdict: **ALREADY-TRACKED-GATE** (joint covariance / systematics closure).
The estimator-dependence is disclosed exhaustively and honestly: Abstract (L751 "WLS and harmonic analyses … retained only as systematics diagnostics … joint covariance … remain open"), headline-summary text (L865: "Their statistics are not commensurable, and no joint likelihood is defined … The missing joint covariance remains an open methodological gate"), Table 1 caption note (L868: "σ values in different rows … are not directly comparable … as detection significances"), estimator callout (L943), diagnostic labels for `+6.923/+7.033` (L836, L1117: "systematics diagnostics, not Gaussian-equivalent tail significances and not cosmological detections"), and open-gates list (L1360). Claude's demand (compute joint covariance OR justify the privileged estimator) is the tracked joint-covariance gate. Not new.

**C4 [MAJOR] — Catalog C ships an uncorrected >9σ class-fraction artifact (f_CW−0.5 = −0.265%, −9.47σ) as user responsibility.**
Verdict: **GENUINELY-NEW-REAL** (bounded; product-completeness; low priority).
The artifact is fully disclosed and characterized: Table 4 `tab:cw_frac` (L1035: Catalog C `−0.265 / −9.47`), §4.2 (L1040), Appendix (L1647). The paper proves via a generative test that a *constant* monopole is absorbed by the fitted monopole term and does **not** bias the primary dipole (L1040), and it states an explicit correction *recipe* in prose ("locally monopole-renormalized (per-region CW-fraction subtraction)"). So the science is not defective and the recipe is not absent. What **is** genuinely absent is a *delivered* pre-computed per-region CW-fraction correction map/column with per-region binomial uncertainty in the release. For an ApJS catalog paper that itself calls this "the single largest false-positive risk in any ℓ=0 chirality-parity study," shipping that map is a bounded, honest product enhancement derivable from already-committed data. Retained per "when in doubt, choose GENUINELY-NEW-REAL," with the honest caveats that (a) it changes no science number, (b) the recipe is already stated, and (c) the correction is computable by users from the released labels + sky positions. Priority: low.
