## KEY ADJUDICATION (1) — Claude M2: honest-negative → "is Catalog C chirality a training prior or robust morphology?"

**Verdict: DISCLOSED-RE-FLAG + ALREADY-TRACKED-GATE (DP4-15 released-classifier image-level validation). NOT genuinely-new-real.**

This correctly blocks the naive inference, but is a defense against a wrong reading, not a positive demonstration.
2. **The paper does not overclaim — so M2's worry is structurally pre-empted.** It never asserts the released chirality is robust morphology; the primary result is an observed-label null and A_95 is disavowed as physical (L905). Claude's own §(3) concedes the *central null* is supported; its complaint is the catalog's *chirality-product* value — which the paper itself concedes ("validation … substantially measures agreement with the CE model," L965/L1652). Paper and reviewer **agree on the facts**; there is no error to fix.
3. **G4's GZ1-prior sign-exclusion does NOT answer M2 directly** — it is the wrong observable.
