Rewrite the synthesis from those results.

The existing excluded-row result in `ext3_nfm1_hc_dipole_qc_rerun.json` uses the obsolete pixel-permutation convention. **Required closure:** reconcile the release semantics. If unsafe means unsuitable for science, rerun the exact fixed-occupancy galaxy-label null on `primary_hc && !raw_flip_qc_unsafe` (890,069 selected rows), using the current deterministic convention, and promote that strict result or remove the contradictory release prohibition with defensible evidence.

Existing artifacts cannot establish independent purity, completeness, or spatial error rates. **Required closure:** perform and archive either a representative training-disjoint human-label audit with spatial/observing-condition strata or a fully reproducible retraining plus held-out validation. Disclosure alone does not close this ApJS catalog-validation gate.
