## Disposition classes

- **A — manuscript/data closure:** supported by exact evidence and feasible without inventing science.
- **B — durable-archive workflow gate:** real but external to the local scientific derivation.
- **C — out-of-scope/new physical validation:** would require unavailable evidence or a new study;
  it must not be fabricated to satisfy a reviewer.
- **D — already satisfied or falsified:** the frozen PDF/release already contains the requested
  fact, or the reviewer's factual premise is contradicted by exact evidence.
