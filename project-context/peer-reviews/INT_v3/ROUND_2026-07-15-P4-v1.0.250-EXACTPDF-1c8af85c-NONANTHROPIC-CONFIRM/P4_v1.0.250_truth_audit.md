## Verified findings

- **REAL, standing MAJOR — training/model provenance.** The exact training objects, split, random state, run receipt, and clean GZ1 training anti-join are unavailable, while committed totals and validation figures conflict. TTA guarantees flip-equivariance of the output protocol; it does not recover or make irrelevant the unknown training realization.
- **REAL, standing MAJOR — spatial transfer and joint covariance.** Fixed-occupancy label randomization supports the narrow observed-label HC null, but it does not calibrate a spatially varying classifier/imaging transfer function. The per-pixel confusion model and joint real-space–harmonic covariance remain open. The paper already discloses these limits, so the review's premise that it claims a calibrated physical or primordial sub-percent null is false; the missing calibration is nevertheless a real publication gate.
- **REAL, standing MAJOR — immutable publication archive.** The catalog payload is pinned, but paper/source/figure/canonical-artifact links still target moving `main`, and a DOI-backed complete snapshot is promised rather than deposited. The machine schema also carries a stale `paper_version: v1.0.248` binding even though the catalog payload version correctly remains v1.0.244.
- **REAL, bounded MINOR — WLS support regression.** Headline Table 2 assigns the historical WLS diagnostic to the 24,087-pixel FS-C support (`f_sky=0.49005`), contradicting the audited 24,187-pixel latitude-cut support stated later in the manuscript.
- **REAL, bounded MINOR — transfer-factor wording.** `g_eff=s_CW+s_CCW-1` and `2a-1` agree to about `6e-4`, but are not exactly identical because pooled accuracy is class-frequency weighted and the true classes are not perfectly balanced. The numerical three-decimal conclusion survives; the exact-identity derivation does not.
- **REAL, bounded MINOR — Monte Carlo tail notation.** The manuscript declares add-one empirical-rank notation for the primary result but labels two diagnostic raw exceedance fractions `15/500` and `43/5000` as p-values. It must either apply `(k+1)/(N+1)` or clearly label those quantities as legacy raw exceedance fractions.
- **REAL, bounded MINOR — release fields.** The safe catalog is intentionally compact, but it does not include or provide an executable versioned join to imaging leg, depth/seeing/PSF, morphology, and redshift/selection metadata used by the systematics discussion.
- **REAL, presentation — audit-heavy prose and raw paths.** The manuscript still reads partly like an internal correction ledger. Withdrawal language and repeated raw repository paths should be consolidated into definitive scientific prose plus one reproducibility table/Data Availability block. The abstract remains denser than necessary.
- **REAL, bounded presentation — bibliography order.** The bibliography claims first-citation order, but `Shamir:2012` is cited before the entries that precede it in the bibliography.

## Not verified as new defects

- **Unsafe-row impact is already supplied.** The public release contains the machine-readable `raw_flip_qc_unsafe` flag and the 249,066-row quarantine. The manuscript reports the exact HC count (59,515), strict sample size (890,069), and excluded-versus-baseline rerun (`z=+0.48` versus `+0.52`) in the bias audit. Grok's request is therefore a presentation/release-discoverability improvement, not a missing analysis.
- **Formal preregistration cannot be retroactively manufactured.** The manuscript explicitly states that no timestamped preregistration, frozen pre-unblinding tag, or independent blinding record exists. This is a real limitation and human-referee risk, but not an editable defect that can be honestly “closed” after seeing the data.
- **The central numerical result remains supported only at its stated scope.** All three reviewers accept the narrow result that the HC observed-label real-space map is null-consistent under the declared fixed-occupancy randomization. None establishes a true-spin, physical-amplitude, primordial-parity, or joint-estimator null.
