## Physics verdict: what the factor of 2 actually is

**Ratio Cai/Li at c_s=1 = (−35/8)/(−35/16) = exactly 2.** Confirmed.

Decisive fact: **the two papers use the SAME f_NL normalization (10/3, Eq. 21 = Eq. 4.20), the SAME local limit (k1≪k2=k3), AND the SAME shape-function polynomial (coefficient-for-coefficient at c_s=1).** Yet the local amplitude they read off differs by exactly 2.

This RULES OUT P2's two stated mechanisms:
1. **NOT the Komatsu–Spergel c=1 vs c=2 convention** (Appendix A's headline story). Both papers already write the same c and the same 10/3 normalization explicitly; there is no residual c-rescaling between them. P2's Appendix A "c=2 vs c=1" framing is factually not the source of the Cai/Li 2.
2. **NOT a demonstrable "Li dropped the second in-in time-ordering"** (the abstract + Appendix A.1 + Sec II.C story). If Li had computed only a single time-ordering (−Im instead of −2Im), Li's ENTIRE shape polynomial would be half of Cai's. It is not — it matches Cai's coefficient-for-coefficient at c_s=1. So the "single-time-ordering intermediate" claim about Li is unsupported by Li's actual paper, and is a fabricated mechanism (pattern-036 class: a math-mechanism claim asserted in closure without a source that supports it — Li's paper contradicts it).

Internal contradiction found in P2 itself: main-text Sec II.C (line 755) FIRST says the four vertices "agree between the two papers at c_s=1 … to six significant figures" and the 2 "resides in … how permutation factors from Wick contractions are absorbed into A_T" (a bookkeeping/convention story), THEN in the same paragraph switches to "Li … single time-ordering … fixed by the −2Im commutator" (a computational-omission story). These are mutually incompatible. The abstract and Appendix A commit fully to the second (computational-omission) story, which is the one contradicted by Li's paper.

**Correct characterization:** both papers evaluate the same four-vertex shape function with the same normalization; the −35/8 vs −35/16 is a genuine, UNRESOLVED factor-of-2 discrepancy in the **local-limit reduction / permutation bookkeeping of a shared shape function** between two overlapping-authorship papers (Cai is a coauthor on both). Which local-limit reduction is correct cannot be settled without redoing the four-vertex in-in conformal-time integrals and the squeezed-limit extraction from scratch — beyond a tractable symbolic check, and NOT established by P2's symbolic identity (which proves a generic in-in identity but does NOT prove Li invoked it wrongly).
