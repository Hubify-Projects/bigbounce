## Confirmed work

1. **Chance-association control — confirmed, major.** The manuscript proves
   nearest/all-neighbor uniqueness inside the declared radii, but that is not a
   background false-association estimate. Add a deterministic random-shift or
   locally matched surface-density control for the 190,015 historical cluster
   positions. Report expected/observed match count as a function of radius and
   isolate the 11 target-to-cluster tail rows. Treat `P3-DESI-000030`, whose
   target-to-original-member separation is 1.979009 arcsec, explicitly. No
   identity claim may be strengthened before this control exists.

2. **Warning-bearing population comparison — confirmed, major but already
   data-enabled.** The r5 auxiliary product makes this closure inexpensive:
   exact rows and fields already exist. The current paper reports the seven
   `ZWARN` masks and SPECTYPE counts, but not the requested accepted-versus-
   rejected distributions. Add a compact comparison of redshift, historical
   score, match separation, and `DELTACHI2`, with language that these are
   descriptive and do not correct selection bias. Direct audit confirms the
   warned table has 2,267 rows, 47 columns, SPECTYPE counts 2,194/72/1
   (GALAXY/QSO/STAR), median `z=0.886051`, median historical score `6.211950`,
   median separation `0.001350` arcsec, and median `DELTACHI2=4.919479`; all
   numbers must be regenerated by a committed script before entering the paper.

3. **Original-member sensitivity — confirmed, bounded.** The manuscript
   already publishes the continuous original-member separation and states that
   exactly one released row exceeds 1 arcsec. Make the counterfactual explicit:
   a 1-arcsec target-to-original-member rule would remove exactly that row. Add
   a derived tier/flag to the machine-readable AAS asset or document a
   deterministic consumer-side expression; do not silently redefine the frozen
   target-to-cluster primary selection.

4. **Historical-score scope/title — partially confirmed.** The exact paper
   already says that the production normalization, resampling, object mapping,
   and physical sensitivity are unavailable; it repeatedly labels the result a
   historical-list positional recovery rather than a validated detection.
   OpenAI's claim that this limitation is absent is therefore a re-flag. A
   title-level change to “historical anomaly-list recovery” and one consolidated
   metadata sentence would nevertheless reduce ambiguity without pretending to
   reconstruct the unavailable anomaly model.

5. **Final citable artifact/archive — confirmed workflow gate.** The exact
   Hugging Face commit is an immutable present reference, while the AAS digital
   asset DOI is honestly described as unassigned. Acceptance still requires a
   final, simple citable package binding the 181-row primary table, optional

   release/workflow gate, not evidence that current row computations are wrong.
