## PASS 2 — self-critique findings (what initial review missed)

[P3-E1] **Arithmetic error in the 58.8% aggregate SIMBAD-unmatched rate.** The paper says the pooled unmatched count is **235/400 at 3″**, which recomputes to **58.75%**, not 58.8% if rounding to one decimal place; if rounded to the nearest tenth, this should be reported as **58.8%** only if the convention is explicit, but the manuscript also treats the value as exact elsewhere, so the rounding basis is unclear.

[P3-E2] **Arithmetic error in the DESI science-class fraction.** The paper states **2,468** DESI anomaly clusters coincide with a primary science-class target bit out of **190,015** clusters, and calls this **1.3%**. Recomputing gives \(2468/190015 = 0.01299\), so **1.30%** is correct; however, the text elsewhere frames this as “**≈ 0.9×** the benchmark’s 2,685,” which is not exact and should be expressed as **0.919×** rather than “≈0.9×” if the manuscript intends a numerical comparison rather than a rough verbal one.

[P3-E3] **Arithmetic error in the DESI object-level fraction.** The paper says **86%** of DESI anomaly clusters have **TARGET = 0** outright and that **∼98.7%** coincide with spectra carrying no primary science-class target bit. Those two statements are not directly comparable, but the manuscript presents them as if they were part of the same denominator story; the base populations differ, so the percentages cannot be juxtaposed without explicit denominator labels.

[P3-E4] **Arithmetic inconsistency in the NEOWISE polar-cap fraction.** The text says **17/436 = 3.9%** retained are rejected from the mask, but also says the **rejected 3.9% polar-cap fraction** corresponds to **2.6×** the uniform-null expectation of **1.52%**. That ratio recomputes to **3.9/1.52 = 2.57×**, so “2.6×” is acceptable only as rounded; the paper should state the rounding convention because it later presents the comparison as quantitative confirmation.

[P3-E5] **Arithmetic inconsistency in the DESI-rate-compression claim.** The manuscript says DESI S>5 on the validated science-target subset is **12** sources versus **77,905** for the continuity slice, giving a “**∼6500×**” anomaly-rate reduction. Recomputing the raw count ratio gives \(77905/12 = 6492.1\), so the stated factor is fine only as an approximation, but the nearby phrase “**∼6500×**” should be tied explicitly to the **77,905 vs. 12** count ratio, not to any rate ratio.

[P3-E6] **Arithmetic mismatch in the DESI top-1% vs. catalog sizes.** The text says the **195,829** DESI anomalies are a **0.87%** rate over **22,504,897** spectra. Recomputing gives \(195829/22504897 = 0.8700\%\), so this is correct; however, the paper later describes the same count as a “**top 1% score-cut**,” which is only approximately true and should not be conflated with the actual measured rate.

[P3-E7] **Arithmetic error in the SDSS native slice percentage.** The manuscript says **77,905 = 4.05%** of the **1,925,279** native-rescored spectra. Recomputing gives \(77905/1925279 = 0.04048\), so **4.05%** is correct, but the same paragraph also describes the slice as “**not a top-1% cut**” while later footnotes refer to “**top-1% proper**” for SDSS. That is internally fine only if the authors clearly distinguish the fixed-size continuity slice from the true top-1% set every time.

[P3-E8] **Arithmetic inconsistency in the LAMOST native pool loss.** The text says **11,418,594** total DR10 spectra minus **84,433** lost gives a native re-score pool of **11,334,161**. Recomputing gives \(11418594 - 84433 = 11334161\), so this is correct; but the same section also refers to **11.4M** input spectra and **11,334,161** scored spectra without making the loss fraction explicit. The implied loss fraction is \(84433/11418594 = 0.7396\%\), i.e. **0.74%**, which should be stated wherever the retrieval failure is used as evidence.

[P3-E9] **Arithmetic inconsistency in the Planck top-200 description.** The paper calls the Planck tier a **top-200** selection and also says the native bank contains **2 × 10^5** patches, which makes the tier **0.10%**, not simply “top-1%” as the general narrative suggests elsewhere. The manuscript does note that the **20,000-patch cross-transfer** input was a top-1% selection and the **200,000-patch native** bank was separate, but that distinction is easy to miss and should be made explicit in any headline summary.

[P3-E10] **Figure-caption vs. body mismatch for Fig. 3.** The caption says the right panel spans **more than ten orders of magnitude** from **S = 5** to **S = 1.9 × 10^11**, while the body states the SDSS native re-score compresses the same objects to **S < 14** and eliminates the \(10^4\)–\(10^{11}\) tail. Those statements are consistent only if the figure is explicitly identified as the **cross-transfer** score axis and the body as the **native** score axis; the caption does say that, but the manuscript should repeat this distinction in the surrounding text because otherwise the magnitude claims look contradictory.

[P3-E11] **Figure-caption vs. body mismatch for Fig. 8 panel annotations.** The caption says the panel values **3.2** and **2.8** are **display values** and “not the catalog selection scores,” while the body says the known QSO is one of the **three highest-confidence cross-survey detections**. Because the figure annotations are not catalog scores, the panel cannot be used to support the “highest-confidence” ranking unless the manuscript separately reports the actual catalog scores for those three matches.

[P3-E12] **Equation consistency issue in Eq. (E1).** The PTA formula is written as \(\log_{10}\rho_i = 21 2 \log_{10}A - \log_{10}(12\pi^2) + \dots\), which visually appears to be missing an operator or exponent formatting between “21” and “2.” As printed, the left-hand side is dimensionless, but the displayed expression is typographically ambiguous and risks being read as a malformed term; the equation should be re-typeset unambiguously.

This is dimensionally fine only if \(F_0\) and \(c\alpha^2\) are both in inverse-\(f_{\rm NL}^2\) units, but the manuscript never states the units or normalization for \(c\). The omission matters because the same section compares \(\sigma(f_{\rm NL})\) values from a different internal normalization in Appendix C.

[P3-E14] **Internal cross-reference problem around Appendix C.** Appendix C says the fixed-\(\alpha = 0.15\) forecast is “**superseded**” and that the primary forecast is in §V, but Appendix C also contains Table VII and Fig. 11 as if they remain operational. [P3-E15] **Internal cross-reference problem around Table IV caveat (i).** The text says the local-linear propagation \(\sigma(f_{\rm NL}) \approx 8.98 - 3.66\alpha\) fails inside the **1σ interval \([-0.46, +0.84]\)** that crosses zero, yet Table IV(c)/(i) are used to justify the Fisher-positivity-respecting form. The summary should explicitly label them as different classes of gate, not a single aggregate pass/fail metric.

The abstract should be revised to match the narrower body claim unless a true cross-paper scale comparison is shown.
