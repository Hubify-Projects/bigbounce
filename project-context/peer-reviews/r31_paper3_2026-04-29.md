## Findings

### P3-R31-1 (MAJOR — fixed) — Bias-validation sample-size conflation

**Location:** §6.3 Limitations, sentence beginning "A preliminary Landy-Szalay two-point correlation analysis of the Pipeline-1 Gold+Silver tracers..."

**Issue:** Paper stated the 1.58× clustering-bias measurement applies to "Gold+Silver tracers" but cited the sample size as "N = 5,384" — which is the *total* QSO_CANDIDATE pool. According to `pipelines/p1_highz_tracers/outputs/step4_bias_validation/bias_validation.json`:

- `gold_silver`: n_objects = **1,122**, relative_bias = **1.5819** (matches the 1.58× claim)
- `gold_only`: n_objects = 116, relative_bias = 0.9657 (no bias enhancement)
- `qso_all`: n_objects = 5,000, relative_bias = 0.964 (essentially baseline)
- `qso_candidates_total` = 5,384

Conflating the bias-measurement subset (1,122) with the total candidate pool (5,384) misrepresents both the sample size of the measurement and the meaning of "Gold+Silver".

**Fix applied:** Updated Limitations passage to read "Gold+Silver tracers (N = 1,122, drawn from the 5,384 QSO-candidate pool: 116 Gold + 1,006 Silver)" and added explicit JSON-artifact citation for reproducibility.

### P3-R31-2 (MINOR — fixed) — Bias-validation artifact path missing

**Location:** Same passage as R31-1.

**Issue:** The 1.58× number is a load-bearing empirical-calibration claim used to justify the α=0.15 fiducial in Section~5. No companion-artifact path was cited, so a referee cannot reproduce or audit the value.

**Fix applied:** Added inline citation `pipelines/p1_highz_tracers/outputs/step4_bias_validation/bias_validation.json` in the same edit as R31-1.

### P3-R31-3 (MINOR — fixed) — Gaia $^\star$ footnote ambiguity (5,000 vs 500)

**Location:** Table 1 footnote $^\star$ ("Reliability warning").

**Issue:** Footnote claimed "more than half of the published top-1% anomaly selection" for Gaia at 41.0% (2048/5000). Two distinct populations with adjacent sample sizes:
- Gaia published catalog (Table 1): 500 objects on 50,000-source subset
- Gaia IF refit reference set (caveat (v)): 5,000 objects on 10×-expanded 500,000-source sample

The footnote conflated them. The 41.0% is measured on the 5,000 reference set, NOT the 500-object published catalog.

**Fix applied:** Footnote now explicitly distinguishes the two scopes — IF cross-validation runs on the 5,000 reference set; the published 500-object Gaia row is the original 50K-source subset.

### P3-R31-4 (MINOR — fixed) — eROSITA $^\S$ footnote ambiguity (298 vs 9,303)

**Location:** Table 1 footnote $^\S$ ("IsolationForest cross-validation").

**Issue:** Footnote cited 81.5% (7582/9303) for eROSITA cross-validation stability, but the Table 1 published eROSITA count is 298 (the data-driven top-cut at S > 0.259). A referee reads "9303" and asks what changed between Table 1's 298 and the footnote's 9303. The 9,303 ≈ 1% of 930,203 (top-1% reference set used for IF refit), and 298 is a strict subset of this set at the higher-purity score-knee threshold.

**Fix applied:** Footnote now explains the 9,303-object reference set is the top-1% IF-refit reference; the published 298 is the harder S > 0.259 score-knee top-cut and is a strict subset.

### P3-R31-5 (MINOR — fixed) — LAMOST native re-score completeness gap

**Location:** §3.3 LAMOST DR10, "Path-C native-retrain in flight" paragraph.

**Issue:** Paper says "$11{,}334{,}161$ spectra scored" against the native checkpoint. The LAMOST DR10 catalog total is 11,418,594. That leaves 84,433 spectra (0.74%) missing from the native re-score with no acknowledgement. By contrast, the SDSS native re-score paragraph thoroughly accounts for its 376,157 missing spectra (16.3%) — explaining the SDSS-III ancillary plate gap and verifying no spatial bias. A symmetric audit was missing for LAMOST.

**Fix applied:** Added an inline accounting clause: "the residual 84,433 spectra (0.74% of the 11,418,594 DR10 catalog) failed batch-level preprocessing on a small number of shards with corrupted or missing flux extensions and are excluded from the native re-score; their exclusion does not affect the headline anomaly-rate reduction below."

### P3-R31-6 (TRIVIAL — not fixed) — Title rounding

**Location:** Title ("378,000 Anomalous Sources from 37 Million Objects").

**Issue:** Title rounds 378,480 down to 378,000 and 37,292,042 down to 37 million. Standard astronomy-paper-title rounding; not a defect. No fix needed.

### P3-R31-7 (TRIVIAL — not fixed) — `\bar{J}_{\rm bm}` rounding

**Location:** §3.2 SDSS clustering paragraph, FW-6 stability claim.

**Issue:** Paper says `\bar{J}_{\rm bm} = 0.90 ± 0.05`. JSON gives mean = 0.901779, std = 0.053019. The rounded "0.90 ± 0.05" is technically tighter than "0.902 ± 0.053" but acceptable scientific rounding; both values cleanly clear the 0.70 gate. No fix needed.
