# Pattern 074 — A paused reviewer leg must be visibly annotated everywhere it renders

**Class:** honest-presentation
**First observed:** 2026-07-23 (GPT column frozen since directive N read as fresh REJECTs)

## Observation
Directive N paused the OpenAI leg on 2026-07-16. The grid kept rendering its
last-tested REJECT cells with no annotation, so a reader concluded the current
papers were being rejected — when the column structurally COULD NOT change.

## Rule
When a leg is paused/retired: annotate it in every surface that renders it
(legend, meter denominator note, round notes), exclude it from any
terminal-criterion arithmetic (directive M-AMENDED), and keep its history
displayed untouched. Silence about a frozen column is a form of dishonesty
even when every cell is individually true.
