## Is it worth continuing ECH-specific perturbation calculations?

**NO.** The gate is closed. The only way to reopen it would be:
1. Going beyond minimal ECH (dynamical Barbero-Immirzi, Nieh-Yan coupling, propagating torsion) — but this is a different theory
2. Including fermion perturbations explicitly — but these decouple from the scalar spectrum at linear order
3. Working at second order in perturbation theory near the bounce — but the corrections are negligible for super-Hubble modes

None of these are worth pursuing given the clear result at the minimal level.
