## 2. The derivation

Units `8πG = 1`, `M_p = 1`, `c_s = 1`. In the dressed-metric/geometric scheme
that A2 uses throughout, the canonical variables are

```
scalar   mu_S = z ζ,           z = a sqrt(2ε),   ε = 3(1+w)/2
tensor   mu_T = (a/2) h_λ      (per polarisation)
```

Both obey `mu'' + (k² − a''/a) mu = 0` for constant ε (`z ∝ a`), and both take
the same Bunch–Davies normalisation `mu → e^{−ikη}/√(2k)`. Hence, with two
tensor polarisations,

```
P_h    = 2·(k³/2π²)·|h|²      = 2·(k³/2π²)·4|mu_T|²/a²
P_ζ    =   (k³/2π²)·|ζ|²      =   (k³/2π²)·|mu_S|²/(2ε a²)
r      = P_h/P_ζ = 16 ε |mu_T/mu_S|²                       [verified symbolically]
```

For the dust contraction `ε = 3/2` **exactly**, and `mu_T = mu_S`, so

> **r = 24, with no free parameter.**

This is the matter bounce's known large-`r` problem (Cai, Easson &
Brandenberger 2012, arXiv:1206.2382; the single-field no-go of Quintin,
Sherkatghanad, Cai & Brandenberger 2015, arXiv:1508.04141; Brandenberger &
Peter 2016 review, arXiv:1603.05834); the scale invariance of the contracting
spectra is the Wands 1999 duality (gr-qc/9809062). We do **not** import a
numerical `r` from any of them — the 24 above is this lab's own.

**Tilt.** `a ∝ (−η)^q` with `q = 2/(1+3w)` gives `P ∝ k^{4−2q}`, i.e.

```
n_s − 1 = n_T = 12w/(1+3w)
```

so **pure dust (`w = 0`) predicts `n_s = 1` exactly**, and the observed
`n_s = 0.9649` is an **anchor that fixes `w = −0.00290`**, not a prediction.
At that `w`, `ε = 1.49565` and `r = 24(1+w) = 23.930`. Because scalars and
tensors share the same `q`, the model predicts the consistency relation
**`n_T = n_s − 1 = −0.0351`** — *not* the single-field-inflation `n_T = −r/8`
(which would be `−2.99` here). That is a sharp, falsifiable difference.

**Deviation from the A2 backgrounds' ε(t) history.** ε departs from 3/2 only
inside the NEC-violating window, i.e. for modes with `kη_B ≳ 1`. CMB scales
have `kη_B ≲ 10^{−30}` for any `T_B ≥ 10^8` GeV (same estimate as A3-3's
`kη_B ≤ 2.3×10^{−8}` across the whole PTA band), so **the bounce contributes no
running to `n_s` or `n_T` on observable scales**; the tilt is set entirely by
the contraction's `w`.

## 3. Numerical propagation through the three A2 bounces

The scalar mode is integrated by A2's own `evolve()` (μ-form, adiabatic-vacuum
ICs deep in contraction); the tensor mode is integrated **independently in

`h = 2 mu_vac/a`. Transfers are amplitude ratios from the NEC boundary `−η_B`

**Why `r` is bounce-invariant.** Tensors are transported by `a''/a` exactly; in
the dressed-metric scheme so are scalars. Both therefore see the *same*
geometric potential and the *same* `{1, J(η)}` super-Hubble branch basis, and
both are growing-branch dominated by the same factor. Whatever the bounce does
to ζ it does identically to h, so `T_h/T_ζ = 1` to integration accuracy
(`≤ 8×10^{−5}`, the Quintin background's piecewise-matched `a` being the least
smooth) and **`r_after = r_before` for every bounce in the A2 set**. No bounce
in this class relieves the tension; a mechanism that suppresses `r` must act on
the *scalar* sector (curvaton/entropy), which is precisely the trade Quintin
