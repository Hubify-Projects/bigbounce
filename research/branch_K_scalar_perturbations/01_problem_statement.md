## Two Distinct Questions

### Question 1: What enters the bounce? (Pre-bounce mechanism)

The scalar power spectrum P_S(k) observed in the CMB must be
GENERATED by some mechanism in the contracting phase. The
minimal spin-torsion bounce does not specify this mechanism.

Possibilities:
- Matter-dominated contraction → P_S ∝ k⁰ (scale-invariant)
- Radiation contraction + vacuum → P_S ∝ k⁴ (blue, excluded)
- Ekpyrotic contraction → depends on model

**This question is OUTSIDE the scope of the minimal model.**
We cannot predict the scalar spectrum without specifying the
pre-bounce cosmology.

### Question 2: How does the bounce modify the spectrum? (Transfer function)

Given an input spectrum P_S,in(k), the bounce produces:

```
P_S,out(k) = |T(k)|² × P_S,in(k)
```

where T(k) is the bounce transfer function. This IS calculable
from the bounce solution alone.

**Branch K focuses on Question 2: the transfer function T(k).**

```

H(t) = -H(-t)
```

is the time-reverse of expansion). This symmetry has a direct
consequence for scalar perturbations:

**In a time-symmetric bounce, the growing mode of the
contracting phase maps to the DECAYING mode of the expanding

unit amplitude.

If this argument holds, then T(k) = 1 EXACTLY for all
super-Hubble modes, and the bounce is perfectly transparent
to scalar perturbations at long wavelengths.

This is simultaneously:
