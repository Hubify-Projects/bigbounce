## 2. Why PGT Specifically

The minimal Einstein-Cartan (EC) bounce operates at the Planck scale
(rho_crit = 0.21 M_Pl^4). Everything observable is 28+ orders of magnitude
below the bounce scale, making the bounce invisible (Branches H, K).

PGT introduces a propagating torsion mass m_T = M_Pl/(2 sqrt(|t_3|)) that
can lower the bounce scale:

```
rho_crit = m_T^2 M_Pl^2
```

For m_T << M_Pl, the bounce occurs at sub-Planckian density. This opens
a wider parameter space and, in principle, moves bounce features to lower
frequencies.

Ghost-free sector: Sector II (spin-0^-) with t_2 = -2 t_1, t_3 < 0.
Sector I (spin-0^+) is rejected due to ghosts at the target mass scale.

## 5. Success Criteria for Branch P

Branch P succeeds (BRANCH_P_PROMISING) if ALL of the following hold:

1. **At least one observable signal survives** -- a prediction that is
   not already killed by Branches H--O
2. **Not already excluded** -- the signal is consistent with current data
3. **Viable parameter region exists** -- ghost-free constraints + observational
   bounds leave a non-empty window
4. **Concrete data-facing prediction** -- a number (or function) that can
   be compared to actual experimental data

Branch P is MIXED if some channels show partial promise but fail on
distinctiveness or reach.

Branch P is WEAK if all channels are either already closed or face gaps
comparable to the 10^{17} vacuum GW gap.

## 6. Honest Starting Assessment

The established results are discouraging:

- The strongest observable channel (GW background) has a 10^{17} gap
- The scalar sector is transparent (T = 1)
- Relics are generic (gravitational democracy)
- Tensor chirality is zero
- The mass-coupling lock suppresses torsion-specific matter couplings

The only escape routes from these closures are:

1. **Non-vacuum GW sources** (parametric resonance, torsion oscillation
   decay, phase transitions near the bounce)
2. **Pre-bounce model specification** (choosing a contraction history
   to get scalar predictions)
3. **Indirect constraints** (BBN, CMB spectral distortions, dark radiation
   from torsion decay products)
4. **Consistency relations** (parameter correlations that could be tested
   even if individual signals are undetectable)
5. **Reheating observables** (if torsion decay sets the reheat temperature)

Whether any of these work is the subject of this branch.
