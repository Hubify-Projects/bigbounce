## What Was Computed

The primordial tensor perturbation spectrum generated by a
radiation-dominated spin-torsion bounce, using:

- Exact background: a(t) = a_b(1 + 4α²t²)^{1/4}
- Tensor mode equation: v_k'' + (k² - a''/a)v_k = 0
- Numerical solution for k/k_b from 0.03 to 16
- Bogoliubov coefficient extraction with normalization verification
- Analytic cross-checks (Born approximation, scattering theory)

## Key Results

### 1. Background

The bounce creates a localized effective potential:

```
a''/a = 2α²a_b² / (1 + 4α²t²)^{3/2}
```

Peak value: 2α²a_b² ≈ 3.52 M_Pl² a_b². This defines the
characteristic scale k_b = a_b √2 α ≈ 1.88 a_b M_Pl.

The potential is ALWAYS POSITIVE and exists ONLY during the
bounce (a''/a = 0 in the pure radiation regime).

### 2. Bogoliubov coefficients

Numerically determined:

```
|β_k|² ≈ 0.855 (k_b/k)²    for k ≪ k_b
|β_k|² → 0                  for k ≫ k_b (exponential)
```

The 1/k² scaling is confirmed to ~3% accuracy and follows from
standard 1D scattering theory (Born approximation for localized
potential).

### 3. Power spectrum

```
P_T(k) ∝ k² × (1 + 2|β_k|²) ≈ CONSTANT    for k ≪ k_b
```

The k² phase-space factor exactly cancels the 1/k² from the
Bogoliubov coefficient, producing a FLAT (scale-invariant)
spectrum.

### 4. Spectral index

```
┌───────────────────────────────────────────────┐
│                                               │
│   n_T ≈ 0    (flat, scale-invariant)          │
│                                               │
│   Numerical: n_T = -0.002 ± 0.01             │
│                                               │
│   NOT blue-tilted. Flat.                      │
│                                               │
└───────────────────────────────────────────────┘
```

### 5. Absolute amplitude

```
P_T ≈ 2 × 10⁻⁶⁴
```

Suppressed by (a_b/a_0)² ≈ 10⁻⁶⁵. This dilution factor is
insurmountable.

### 6. Characteristic frequency

```
f_b ≈ 8 GHz
```

The spectrum is flat from f = 0 up to f_b, then falls off.

## Assessment Against Success Criteria

### Does the bounce produce a distinctive tensor signal?

**NO.** The spectrum is flat (n_T ≈ 0) and this result is GENERIC
for any radiation-dominated bounce. It is not specific to the
spin-torsion mechanism. The only model-dependent quantities are:
- The amplitude (set by α and a_b → encodes ρ_crit)
- The cutoff scale k_b (set by a_b × M_Pl)

But neither is observable.

### Does the spectrum differ from inflation?

**MARGINALLY.** Inflation predicts n_T = -r/8 ≈ -0.005 (slightly
red). The bounce gives n_T ≈ 0 (flat). The difference is:

```
Δn_T ≈ 0.005
```

In principle distinguishable, but:
1. The bounce amplitude is 10⁵⁰+ below detection threshold
2. Even with observable amplitude, Δn_T = 0.005 would require
   exquisite precision to measure
3. n_T ≈ 0 is degenerate with matter bounce models

### Could the prediction be tested?

**NO.** The amplitude is below detection threshold at EVERY
frequency band by at least 10⁴ orders of magnitude:

| Band | Gap to detection |
|------|-----------------|
| CMB | 10⁵² |
| PTA | 10³⁶ |
| LISA | 10²⁰ |
| ET/LIGO | 10¹⁵ |
| HF (GHz) | 10⁴ |

The closest approach is at GHz frequencies, where proposed
high-frequency GW detectors are at the concept stage.

## Why the Verdict is WEAK, Not GENERIC

The verdict is WEAK rather than GENERIC because:

1. The spectrum IS calculable and well-defined (not ambiguous)
2. The spectral shape IS a definite prediction (n_T = 0, flat)
3. The signal IS present (|β|² > 0, gravitons are produced)

But the signal is WEAK because:
1. Amplitude ~10⁻⁶⁴ (below all detection thresholds)
2. n_T = 0 is shared with matter bounce (not distinctive)
3. The characteristic scale (GHz) is far above all detectors

## The Structural Lesson

**The bounce cannot produce observable tensor perturbations for
the SAME reason it cannot produce dark energy: scale separation.**

The bounce operates at M_Pl for ~t_Pl. Observations probe
H₀ ~ 10⁻⁶⁰ M_Pl at scales ~H₀⁻¹ ~ 10⁶⁰ l_Pl. The 10⁶⁰ gap
manifests as:

- For dark energy: ρ_bounce/ρ_DE ~ 10¹²² (Foundations A–G)
- For perturbations: P_T(bounce)/P_T(observable) ~ 10⁵⁰+

This is not a failure of the model — it is a structural property
of Planck-scale physics. Any single-bounce, radiation-dominated
model faces the same limitation.

## What Would Change the Story

The tensor spectrum could become observable if:

1. **Pre-bounce contraction phase** with w ≠ 1/3 (matter or
   ekpyrotic): This would amplify modes at CMB scales through
   horizon exit during contraction. But this is ADDITIONAL physics
   beyond the spin-torsion bounce.

2. **Multiple bounces** (cyclic cosmology): N bounces could
   amplify by factor N. But Foundation G showed cyclic cosmology
   is incompatible with Λ_obs.

3. **Non-standard bounce** at E ≪ M_Pl: If ρ_crit ≪ M_Pl⁴,
   the bounce happens at lower energy, reducing the dilution
   factor. But ρ_crit = 0.21 M_Pl⁴ is DERIVED from EC gravity,
   not a free parameter.

None of these are available within the MINIMAL spin-torsion bounce.
