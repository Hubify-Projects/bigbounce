# Phase 2A — Unitarity Bounds on |t_3|

**Date:** 2026-03-13
**Status:** Original analysis

---

## 1. Setup

We want to know whether tree-level unitarity places an upper bound on |t_3|
that would exclude the cosmologically interesting regime |t_3| >> 1.

The relevant process is fermion-fermion scattering mediated by the 0-
axial torsion mode:

```
psi psi -> A_mu (0- torsion) -> psi psi
```

The amplitude is governed by the propagator and coupling structure of the
canonically normalized axial field.

---

## 2. Tree-Level Amplitude

The 4-fermion amplitude from single A_mu exchange is:

```
M(psi psi -> psi psi) = g_eff^2 * (J_5^mu) D_{mu nu}(k) (J_5^nu)
```

where:
- g_eff = kappa / sqrt(Z_A) ~ 1/(M_Pl sqrt(|t_3|)) is the canonical coupling
- D_{mu nu}(k) = (-g_{mu nu} + k_mu k_nu / m_B^2) / (k^2 - m_B^2) is the
  massive vector propagator
- J_5^mu = psi_bar gamma^mu gamma_5 psi is the axial current

At center-of-mass energy sqrt(s), the partial-wave amplitude for the
J=1 channel scales as:

```
a_1 ~ g_eff^2 s / (s - m_B^2)
```

The unitarity bound requires |Re(a_J)| <= 1/2 for each partial wave.

---

## 3. Unitarity Violation Scale

Setting |a_1| = 1/2 gives the unitarity violation scale:

```
sqrt(s_unit) ~ 1 / g_eff ~ M_Pl sqrt(|t_3|)
```

This is the critical result: **the unitarity violation scale RISES with
|t_3|.** Explicitly:

| |t_3| | m_B (eV) | sqrt(s_unit) | Ratio s_unit/m_B |
|-------|----------|-------------|-----------------|
| 1 | 3.4e26 | ~M_Pl | ~1 |
| 10^10 | 3.4e21 | ~10^5 M_Pl | ~10^5 |
| 10^58 | 7.1e-3 | ~10^29 M_Pl | ~10^55 |
| 10^118| 3.4e-33 | ~10^59 M_Pl | ~10^92 |

At large |t_3|, unitarity is violated only at energies exponentially above
the Planck scale. The EFT is under perturbative control at ALL physically
accessible energies.

---

## 4. Comparison with W Boson Analogy

In the Standard Model, the W boson coupling g ~ 0.65 gives:

```
sqrt(s_unit) ~ 4 pi m_W / g ~ 1.2 TeV
```

This is accessible, so the Higgs mechanism is needed. For Model B:

```
sqrt(s_unit) ~ 4 pi m_B / g_eff ~ 4 pi M_Pl^2 sqrt(|t_3|) / 1 ~ 10^{29} M_Pl (at |t_3| = 10^58)
```

The "Higgs problem" for Model B is at an absurdly high scale. No UV
completion mechanism is needed for cosmological purposes.

---

## 5. Longitudinal Mode Scattering

For massive vectors, the most dangerous unitarity constraint typically
comes from longitudinal mode scattering:

```
A_L A_L -> A_L A_L
```

where the longitudinal polarization epsilon_L ~ k/m grows with energy.
The amplitude for this process in a Proca-like theory scales as:

```
M(A_L A_L -> A_L A_L) ~ lambda_4 (s/m^2)^2
```

where lambda_4 is the quartic self-coupling. In Model B, the self-coupling
is generated by the torsion-squared term and gravitational interactions:

```
lambda_4 ~ g_eff^2 m_B^2 / M_Pl^2 ~ 1 / (M_Pl^4 |t_3|^2)
```

The resulting unitarity scale from longitudinal scattering:

```
sqrt(s_unit^(long)) ~ m_B / lambda_4^{1/4} ~ M_Pl |t_3|^{1/4}
```

This also rises with |t_3|. There is no longitudinal-mode unitarity
crisis.

---

## 6. Is There ANY Upper Bound on |t_3|?

From tree-level unitarity analysis: **NO.**

There is no upper bound on |t_3| from perturbative unitarity. The theory
becomes MORE perturbative as |t_3| increases. This is the hallmark of a
decoupling limit.

The only "bound" is the physical irrelevance bound: beyond some |t_3|,
the torsion mode is so weakly coupled that it cannot produce any
observable effect distinguishable from the gravitational sector. This
is a phenomenological failure, not a consistency failure.

---

## 7. Comparison with Existing Literature

The unitarity analyses most relevant to this question:

- **Karananas (2015):** Studies tree-level unitarity in PGT. Finds that
  ghost-free models are perturbatively well-defined. Does NOT report an
  upper bound on the torsion-squared couplings from unitarity. This is
  consistent with our finding — unitarity constrains the coupling signs
  (ghost freedom) but not their magnitudes in the decoupling direction.

- **Neville (1980, 1982):** Early unitarity analysis of PGT modes.
  Identifies which parameter regions give ghost-free propagators. The
  ghost-free conditions are sign constraints (t_3 < 0), not magnitude
  constraints.

- **Sezgin & van Nieuwenhuizen (1980):** Particle spectrum analysis.
  The conditions for absence of tachyons and ghosts are sign and ratio
  constraints, not magnitude bounds.

**No source in the PGT literature reports an upper bound on |t_I| from
unitarity.** This is consistent with our analysis showing the theory
decouples rather than violates unitarity at large |t_I|.

## 8. Summary

| Question | Answer |
|----------|--------|
| Does unitarity bound |t_3| from above? | **NO** |
| Does large |t_3| violate perturbative unitarity? | **NO — theory becomes MORE perturbative** |
| What is the unitarity violation scale? | sqrt(s) ~ M_Pl sqrt(|t_3|) >> M_Pl |
| Is the longitudinal mode dangerous? | **NO — self-coupling also suppressed** |
| Is this good news for cosmology? | **NO — it means the mode is phenomenologically inert** |

The absence of a unitarity bound is the decoupling limit at work. The
theory is consistent at any |t_3|, but becomes observationally empty
as |t_3| grows.
