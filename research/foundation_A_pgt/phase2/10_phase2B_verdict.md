## Evidence Summary

### Document 07 — Shift Symmetry Analysis

Five candidate symmetries investigated. Results:

| Candidate | Status |
|-----------|--------|
| U(1) gauge symmetry | NOT AVAILABLE in PGT |
| Constant/pseudoscalar shift | BROKEN by all Lagrangian terms |
| Conformal/Weyl symmetry | CONCEIVABLE but requires a full model that doesn't exist |
| Chiral symmetry | IRRELEVANT (acts on fermions, not connection) |
| Topological protection | NOT APPLICABLE (A_mu is not a topological quantity) |
| Supersymmetry | NOT PRACTICAL (torsion is algebraic in standard SUGRA) |

**No known symmetry of PGT protects the 0- axial torsion mass.**

### Document 08 — Radiative Stability

Three loop sources analyzed:

| Source | Correction | Fine-tuning at m = meV |
|--------|-----------|----------------------|
| Graviton loop | M_Pl^2/(16 pi^2) | 1 in 10^57 |
| Fermion loop | m_B^2/(16 pi^2) | None (self-consistent) |
| Self-interaction loop | m_B^2/(16 pi^2) | None (self-consistent) |

The fermion and self-interaction loops respect the decoupling structure
(their corrections are proportional to m_B^2). But the graviton loop is
universal and generates delta m_B^2 ~ (10^17 GeV)^2 regardless of the
tree-level mass.

**The mass is not technically natural** ('t Hooft test fails: m_B = 0
does not restore any symmetry within PGT).

### Document 09 — Reduced Action

Model B reduces to GR + massive Proca pseudovector (NOT GR + ALP):
- 3 DOF (vs 1 for ALP)
- Axial current coupling (vs F F~ for ALP)
- Vector perturbation modes (vs scalar only for ALP)

But all distinctive features are suppressed at large |t_3| by the
decoupling limit. The geometric origin is invisible in the reduced
action — no observation can distinguish Model B from a fundamental
Proca field at low energies.

## Why PHASE2B_NO_PROTECTION

The NO_PROTECTION verdict is based on:

1. **No demonstrated symmetry** protects the mass. The only conceivable
   mechanism (conformal PGT) is an unbuilt model, not a result.

2. **Radiative corrections destroy the hierarchy.** The graviton loop
   generates delta m^2 ~ M_Pl^2/(16 pi^2), requiring fine-tuning of
   1 in 10^57 for m ~ meV. This is the standard gravitational hierarchy
   problem with no torsion-specific resolution.

3. **The 't Hooft naturalness criterion fails.** Setting m_B = 0 does
   not enhance the symmetry of the PGT action (no gauge symmetry is
   restored).

4. **The problem is as severe as the cosmological constant problem.**
   The torsion mass hierarchy m_B/M_Pl ~ 10^{-31} is comparable to
   the CC hierarchy Lambda^{1/4}/M_Pl ~ 10^{-31}. PGT has not solved
   the hierarchy — it has rewritten it in different notation.

## The Conformal PGT Loophole

The one remaining possibility — conformal PGT with controlled Weyl
symmetry breaking — is not evaluated here because it requires:

1. A complete conformal PGT action (partially explored by Blagojevic,
   Hehl, Obukhov, but not for propagating torsion phenomenology)
2. A symmetry-breaking mechanism that generates m_B ~ meV from an
   intermediate scale v_c ~ 10^7 GeV
3. Verification that the 0- mode propagates and is ghost-free in the
   conformal extension
4. Analysis of whether conformal PGT evades the decoupling limit
   (it may not — the decoupling structure could persist)

This is a separate research program. It does not rescue Model B within
standard (non-conformal) PGT.
