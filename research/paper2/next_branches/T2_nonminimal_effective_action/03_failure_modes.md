## Predeclared Failure Modes

| Code | Failure mode | Description | Likelihood |
|------|-------------|-------------|-----------|
| FM-T2-1 | Ordinary renormalization | No novel finite-γ content beyond standard RG | 35% |
| FM-T2-2 | Background-dependent novelty | Novel terms appear only on special backgrounds (e.g., de Sitter) but not as functionals | 15% |
| FM-T2-3 | No IR persistence | All γ-dependent terms are curvature-local and vanish as R → 0 | 20% |
| FM-T2-4 | Wrong-sign vacuum | Vacuum contribution exists but has wrong sign | 10% |
| FM-T2-5 | Instability | Non-minimal sector introduces ghosts or gradient instabilities | 5% |
| FM-T2-6 | No predictive power | Result depends on arbitrary non-minimal coupling constants | 25% |
| FM-T2-7 | Intractable computation | Required computation (e.g., full graviton one-loop) is not completable | 20% |

Note: probabilities overlap because multiple failure modes can fire simultaneously.
