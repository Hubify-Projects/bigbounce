# 04: Discrimination Thresholds

## Decision Table for f_NL^local Measurement

| Measured f_NL | Verdict | Reasoning |
|--------------|---------|-----------|
| f_NL = -4.4 ± 0.5 | **CONFIRMS** bounce | Within 1σ of -35/8, 8.8σ from zero. No natural inflation explanation. |
| -6 < f_NL < -3 | **STRONGLY SUPPORTS** bounce | Correct sign and order of magnitude. Hard for inflation. |
| -3 < f_NL < -1 | **SUPPORTS but ambiguous** | Correct sign but smaller than predicted. Could be modified bounce or exotic inflation. |
| -1 < f_NL < +1 | **KILLS** the matter bounce flagship | f_NL ≈ 0 is the inflation prediction. If σ ~ 0.5, this excludes -4.375 at >6σ. |
| +1 < f_NL < +5 | **KILLS** bounce, **supports** inflation variants | Positive large f_NL suggests curvaton-type inflation, not bounce. |
| f_NL > +5 | **KILLS** both standard models | Neither standard bounce nor standard inflation predicts this. New physics needed. |

## Decision Table for r

| Measured r | Verdict | Reasoning |
|-----------|---------|-----------|
| r < 10⁻³ | **CONSISTENT** with LQC bounce | r ~ 10⁻⁴ is the prediction |
| 10⁻³ < r < 0.01 | **WEAKLY CONSISTENT** | Above the LQC prediction but within possible model variations |
| 0.01 < r < 0.036 | **TENSION** | Above LQC prediction. Would require modified quantum corrections. |
| r > 0.036 | Already excluded | Current data already rule this out |

## Decision Table for n_s

| Measured n_s | Verdict | Reasoning |
|-------------|---------|-----------|
| 0.960-0.968 | **CONSISTENT** | Within the quasi-dust range (ε = 0.003 ± 0.0003) |
| 0.955-0.960 | **REQUIRES** larger ε | Still possible but less natural for Λ-driven quasi-dust |
| n_s > 0.970 | **TENSION** | Would require ε < 0.0025, hard to motivate from Λ alone |
| n_s < 0.955 | **SERIOUS TENSION** | Requires ε > 0.004, approaching non-dust EOS |

## Combined Decision Matrix

The most powerful discrimination comes from f_NL ALONE. But joint measurements strengthen the case:

| f_NL ≈ -4 AND n_s ≈ 0.964 AND r < 10⁻³ | **STRONGLY CONFIRMS** bounce paradigm |
| f_NL ≈ -4 BUT n_s ≠ 0.964 | PARTIAL — f_NL supports bounce but tilt doesn't match quasi-dust |
| f_NL ≈ 0 AND n_s ≈ 0.964 AND r < 0.01 | **KILLS** bounce, supports Starobinsky inflation |
| f_NL ≈ 0 AND n_s ≈ 0.964 AND r ≈ 0.003 | **KILLS** bounce, confirms Starobinsky specifically |

## The Kill Condition

**The matter-bounce flagship lane is KILLED if MegaMapper measures |f_NL^local| < 1 with σ < 0.5.** This would exclude f_NL = -4.375 at > 6σ significance and remove the only parameter-free discriminator.

No other observable can rescue the bounce if f_NL ≈ 0, because n_s and r are easily mimicked by inflation.

## The Confirm Condition

**The matter-bounce is STRONGLY SUPPORTED if MegaMapper measures f_NL = -4 ± 1 with σ < 1.** This would be:
- 3-5σ from zero (evidence for non-Gaussianity)
- Correct sign (negative, matching the bounce prediction)
- Correct magnitude (within 25% of -35/8)
- Nearly impossible to explain with standard single-field inflation

Combined with n_s ≈ 0.964 and r < 0.01, this would constitute the strongest evidence for bounce cosmology ever obtained.
