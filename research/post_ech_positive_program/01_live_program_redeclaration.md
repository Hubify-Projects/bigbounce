# Live Program Redeclaration

## What This Project Is Now

**A generic matter-bounce observable cosmology program**, benchmarked against standard inflation, with emphasis on mechanism-robust predictions.

The project studies whether the universe underwent a bounce (contracting → expanding transition) rather than beginning with inflation, and identifies observational tests to distinguish these scenarios.

## Main Research Trunk

**Generic Matter-Bounce Perturbation Phenomenology**

Core observable: f_NL = -35/8 (local-type, parameter-free, mechanism-independent)

Properties:
- Computed from the contracting phase only (no bounce-mechanism dependence)
- Valid for ANY matter-dominated contraction with BD vacuum and standard GR perturbations
- Template projection cos(θ) ≈ 0.95 with local shape
- MegaMapper forecast: 8.3σ detection at σ(f_NL) = 0.5
- SPHEREx forecast: 4.2σ detection at σ(f_NL) = 1.0
- Negative sign distinguishes from slow-roll inflation (which gives f_NL ≈ 0)

Additional generic predictions:
- Scale-invariant scalar spectrum (n_s ≈ 1, no tilt from ε correction)
- Large tensor-to-scalar ratio (r ~ O(1) — potential tension with observations)
- Blue-tilted tensor spectrum (n_T > 0, opposite to inflation)

## Secondary Tracks

- β ≈ 0.27° predicted, 0.35 ± 0.09° observed (3.9σ combined)
- LiteBIRD falsifiable
