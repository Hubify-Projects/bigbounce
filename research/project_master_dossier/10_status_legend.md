# Status & Rating Legend

This document defines the consistent labels used across the entire dossier.

---

## Branch / Result Status

| Status | Meaning |
|--------|---------|
| **ACTIVE** | Work in progress; not yet decided |
| **PASS** | Scientific question answered positively; result is affirmative |
| **FAIL** | Scientific question answered negatively; route is closed |
| **MIXED** | Partial positive, partial negative; some elements survive |
| **CLOSED** | Fully investigated and concluded (may be PASS or FAIL) |
| **DEFERRED** | Not pursued; may revisit if conditions change |
| **SUPERSEDED** | Replaced by a later branch or analysis |

---

## Novelty Scale

| Rating | Label | Definition |
|--------|-------|------------|
| **N0** | Not novel | Already known in the literature; no new contribution |
| **N1** | Weakly novel | Incremental framing, minor extension, or pedagogical restatement |
| **N2** | Moderately novel | New implementation, sharp test, or systematic closure of a known question |
| **N3** | Strongly novel | Likely publishable as independent result; new theorem, prediction, or constraint |
| **N4** | Highly novel | Flagship-level breakthrough; changes how the community thinks about the problem |

---

## Publication Potential

| Rating | Definition |
|--------|------------|
| **LOW** | Insufficient novelty or significance for standalone publication |
| **MODERATE** | Could appear as a section in a larger paper or as a brief report |
| **HIGH** | Stands alone as a focused paper in a good journal (JCAP, PRD) |
| **FLAGSHIP** | Lead result for a high-impact paper (PRL, PRD Rapid Comm.) |

---

## Reproducibility Status

| Label | Meaning |
|-------|---------|
| **COMPLETE** | Full pipeline exists; can reproduce from scratch |
| **PARTIAL** | Some components exist; gaps documented |
| **BROKEN** | Code or configs exist but don't run in current environment |
| **STALE** | Was complete but dependencies or data have changed |
| **MISSING** | No reproducibility assets exist |

---

## Deliverable Status

| Label | Meaning |
|-------|---------|
| **AUTHORITATIVE** | Current, correct, canonical source |
| **DRAFT** | Work in progress; may change |
| **OBSOLETE** | No longer accurate; kept for historical reference |
| **ARCHIVED** | Snapshot of a previous state; superseded by newer version |
| **SUPERSEDED** | Replaced by a specific newer deliverable |
