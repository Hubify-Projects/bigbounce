## Toy Model 1: Torsion-Enhanced Baryogenesis via Axial Chemical Potential

### Setup

Consider a hot fermion plasma at the bounce with:
- Temperature T ~ M_Pl ~ 1.2 x 10^{19} GeV (ECH)
- Net axial charge density n_5 (initial condition, unknown)
- Sphaleron rate Gamma_sph ~ alpha_W^5 T^4 ~ (1/30)^5 T^4 ~ 4 x 10^{-8} T^4
- Torsion-induced axial chemical potential mu_5 ~ (3kappa/8) n_5

### Key Equations

The baryon asymmetry generated by biased sphaleron transitions:

```
d(n_B)/dt = -N_f * Gamma_sph * (mu_B + mu_5) / T
```

where N_f = 3 is the number of families and mu_B is the baryon
chemical potential.

In the regime mu_5 << T (linear response):

```
eta_B ~ (N_f * Gamma_sph / s) * (mu_5 / T) * Delta_t
```

where s ~ (2pi^2/45) g_* T^3 is the entropy density.

### Plugging in Numbers (ECH)

```
mu_5 ~ (3 * 8piG / 8) * n_5 = 3pi G n_5

G = M_Pl^{-2},  so  mu_5 = 3pi n_5 / M_Pl^2
```

At T ~ M_Pl, in thermal equilibrium, n_5 ~ 0 (chirality flipping
is rapid). Non-equilibrium n_5 depends on initial conditions.

**Maximum possible n_5:** If ALL fermions are chiral (maximally
asymmetric):

```
n_5^max ~ T^3 ~ M_Pl^3
mu_5^max ~ 3pi M_Pl^3 / M_Pl^2 ~ 10 M_Pl
```

This exceeds T, so the linear response breaks down. Use the
non-perturbative result:

```
eta_B ~ N_f * Gamma_sph * Delta_t / s * min(mu_5/T, 1)
```

With Gamma_sph ~ 4 x 10^{-8} T^4, s ~ 100 T^3, Delta_t ~ 1/T
(one Hubble time at the bounce):

```
eta_B ~ 3 * (4 x 10^{-8} T^4) * (1/T) / (100 T^3) * O(1)
     ~ 3 * 4 x 10^{-8} / 100
     ~ 10^{-9}
```

### Result

```
eta_B ~ 10^{-9} * (n_5 / n_5^max)
```

**Strikingly, this is in the right ballpark!** For maximal initial
chirality, eta_B ~ 10^{-9}, close to the observed 6 x 10^{-10}.

### Critical Assessment

1. **The result requires n_5 ~ n_5^max.** This is the MAXIMUM
   possible chirality -- every fermion must be chiral. There is no
   reason for this to be the case, and the bounce does not set it.

2. **The mu_5 enters only as a BIAS.** The CP violation (which
   determines the SIGN of the asymmetry) must come from CKM/PMNS
   phases. Torsion does not provide CP violation.

3. **Standard gravitational scattering also thermalizes at T ~ M_Pl
   with G^2 T^5 ~ T.** The torsion (J^5)^2 interaction adds one
   channel among many. The SPECIFIC asymmetry from this channel vs
   generic gravitational channels is:

   ```
   (torsion contribution) / (all gravitational) ~ 1/g_* ~ 1/100
   ```

   Not dominant, not unique.

4. **The result is proportional to n_5, which is a free parameter.**
   We can fit ANY eta_B by choosing n_5 appropriately. This is
   tunable storytelling, not prediction.

### Biggest Ambiguity

The initial n_5 at the bounce. This is completely unconstrained
by the model. Without a mechanism to SET n_5, the model explains
nothing.

### Where Bounce/Torsion Enters

- mu_5 ~ G n_5 (torsion-specific coupling)
- But G n_5 is also the generic gravitational coupling to chirality
- The bounce provides Delta_t ~ t_Pl, but any Planck-temperature
  epoch does the same

### Verdict

**Numerically interesting (10^{-9}) but not predictive (n_5 free)
and not torsion-specific (gravitational thermalization dominates).**

## Toy Model 2: Gravitational Production of Superheavy DM at the Bounce

### Setup

A scalar dark matter candidate chi with mass m_chi, minimally
coupled to gravity, produced by nonadiabatic vacuum amplification
during the bounce.

### Key Equations

The mode equation:

```
chi_k'' + [k^2 + a^2 m_chi^2 - (a''/a)] chi_k = 0
```

For the bounce background a(eta) with conformal time eta:

```
a''/a ~ alpha^2 a^4 ~ alpha^2  (at bounce, a ~ a_b ~ 1)
```

where alpha ~ M_Pl (ECH) or alpha ~ m_T (PGT).

The Bogoliubov coefficient for a smooth, symmetric bounce:

```
|beta_k|^2 ~ exp(-pi k^2 / (alpha m_chi))     for m_chi < alpha
|beta_k|^2 ~ exp(-pi m_chi / alpha)             for m_chi > alpha
```

The number density:

```
n_chi = (1/2pi^2 a^3) integral k^2 |beta_k|^2 dk
      ~ alpha^3 / (2pi^2) * f(m_chi/alpha)
```

where f(x) ~ 1 for x < 1 and f(x) ~ exp(-pi x) for x > 1.

### Plugging in Numbers (ECH: alpha ~ M_Pl)

For m_chi < M_Pl:

```
n_chi ~ M_Pl^3 / (2pi^2) ~ 10^{56} GeV^3
```

This is the MAXIMUM possible production -- O(1) particle per Planck
volume. The relic density today:

```
Omega_chi h^2 ~ (m_chi * n_chi / s) * (s_0 / rho_crit,0)
             ~ (m_chi / M_Pl) * (M_Pl^3 / s) * (s_0 / rho_crit,0)
```

At the bounce, s ~ g_* T^3 ~ 100 M_Pl^3, so n_chi/s ~ 10^{-2}.

```
Omega_chi h^2 ~ 10^{-2} * (m_chi / 10^{19} GeV) * (s_0 / rho_crit,0)
             ~ 10^{-2} * (m_chi / 10^{19} GeV) * 3.6 x 10^{9}
             ~ 3.6 x 10^{7} * (m_chi / 10^{19} GeV)
```

For Omega_chi h^2 = 0.12:

```
m_chi ~ 0.12 / (3.6 x 10^{7}) * 10^{19} GeV ~ 3 x 10^{10} GeV
```

### Plugging in Numbers (PGT: alpha ~ m_T)

For m_T ~ 10^7 GeV:

```
n_chi ~ m_T^3 / (2pi^2) ~ 10^{20} GeV^3
s ~ 100 * (m_T M_Pl)^{3/2} / M_Pl^{3/2} ~ ???
```

Wait -- the temperature at the PGT bounce is T ~ rho^{1/4} ~
(m_T^2 M_Pl^2)^{1/4} = (m_T M_Pl)^{1/2} ~ 10^{13} GeV for
m_T = 10^7 GeV.

```
s ~ 100 T^3 ~ 100 * 10^{39} GeV^3 = 10^{41} GeV^3
n_chi ~ m_T^3 ~ 10^{21} GeV^3
n_chi / s ~ 10^{-20}
```

```
Omega_chi h^2 ~ 10^{-20} * (m_chi / 10^{19} GeV) * 3.6 x 10^{9}
             ~ 3.6 x 10^{-11} * (m_chi / 10^{19} GeV)
```

For Omega_chi h^2 = 0.12:

```
m_chi ~ 0.12 / (3.6 x 10^{-11}) * 10^{19} GeV ~ 3 x 10^{28} GeV
```

This exceeds M_Pl. No consistent solution for PGT with m_T ~ 10^7 GeV.
Need m_chi < m_T for efficient production, which gives
Omega << 0.12.

### Result (ECH)

```
m_chi ~ 3 x 10^{10} GeV  for Omega_DM h^2 = 0.12
```

This is in the "wimpzilla" mass range, consistent with standard
gravitational production estimates (Chung, Kolb, Long 1998).

### Critical Assessment

1. **The result is IDENTICAL to standard gravitational production.**
   The specific bounce profile enters only through the O(1) shape
   of |beta_k|^2, which changes m_chi by a factor of a few -- not
   a qualitative or torsion-specific prediction.

2. **Any Planck-scale bounce gives the same m_chi ~ 10^{10} GeV.**
   The prediction constrains m_chi, not the torsion model.

3. **The (J^5)^2 interaction plays NO role.** The production is
   purely gravitational (minimal coupling to the metric). Torsion
   is entirely decorative.

### Biggest Ambiguity

The dark matter mass m_chi, coupling xi_R, and spin. For fermionic
DM, the (J^5)^2 interaction provides an additional production
channel, but this is sub-dominant to metric-mediated production.

### Where Bounce/Torsion Enters

- Bounce profile a(t): determines |beta_k|^2 shape (O(1) correction)
- (J^5)^2: does NOT enter for scalar DM; sub-dominant for fermionic DM
- rho_crit: sets the overall production scale (same as any bounce at
  same energy)

### Verdict

**Standard gravitational production. Torsion is decorative.
FAIL_GENERIC.**

## Toy Model 3: Bounce-Modified Axion Abundance

### Setup

QCD axion with mass m_a ~ Lambda_QCD^2 / f_a, decay constant f_a,
initial misalignment angle theta_i.

### Key Equations

The axion relic density from vacuum misalignment:

```
Omega_a h^2 ~ 0.12 * (f_a / 10^{12} GeV)^{7/6} * theta_i^2
```

The axion starts oscillating when 3H(T_osc) ~ m_a(T_osc). For the
QCD axion, T_osc ~ 1 GeV.

### Where the Bounce Could Enter

The bounce modifies H(t) at t ~ t_Pl. The axion equation of motion:

```
theta'' + 3H theta' + m_a^2(T) sin(theta) = 0
```

During the bounce epoch, H ~ M_Pl and m_a(T ~ M_Pl) is either:
- Zero (if chiral symmetry is restored, as expected at T >> Lambda_QCD)
- Or ~ Lambda_QCD^2/f_a ~ 10^{-5} eV << M_Pl

In either case, the axion is FROZEN during the bounce:
m_a / H_bounce ~ 10^{-5} eV / 10^{43} eV ~ 10^{-48}.

The axion field does not move during the bounce. It sits at theta_i
from before the bounce until T drops to ~Lambda_QCD billions of
years of expansion later.

### Numerical Estimate of Bounce Effect

Change in theta during the bounce:

```
Delta_theta ~ (m_a^2 / H_bounce) * Delta_t_bounce * sin(theta_i)
            ~ (10^{-10} eV^2 / 10^{43} eV) * (10^{-43} s) * sin(theta_i)
            ~ 10^{-96} * sin(theta_i)
```

**The bounce changes the axion angle by 10^{-96} radians.** This
is not a rounding error -- it is literally zero to any conceivable
precision.

### Verdict

**The bounce is irrelevant to axion physics by 96 orders of
magnitude. FAIL_TOO_WEAK.** This is the cleanest kill in Branch N.

## Toy Model 4: PBH Formation from Bounce-Scale Perturbations

### Setup

Density perturbations at the bounce scale k_b collapse to PBHs
when they re-enter the horizon.

### Key Equations

PBH mass from horizon re-entry:

```
M_PBH ~ M_Pl^2 / H(t_re-entry)
```

For modes at k = k_b ~ alpha (where alpha ~ M_Pl for ECH):

```
t_re-entry ~ 1/alpha (they re-enter immediately)
H(t_re-entry) ~ alpha ~ M_Pl
M_PBH ~ M_Pl^2 / M_Pl ~ M_Pl ~ 2 x 10^{-5} g
```

Hawking evaporation time:

```
t_evap ~ (M_PBH / M_Pl)^3 * t_Pl ~ t_Pl ~ 5 x 10^{-44} s
```

**Planck-mass PBHs evaporate in one Planck time.** They cannot be
relics.

### PGT Case

For PGT with m_T ~ 10^7 GeV:

```
k_b ~ m_T ~ 10^7 GeV
M_PBH ~ M_Pl^2 / m_T ~ 10^{38} / 10^7 GeV ~ 10^{31} GeV ~ 10^8 g
t_evap ~ (10^8 g / 10^{-5} g)^3 * 10^{-44} s ~ 10^{39} * 10^{-44} s ~ 10^{-5} s
```

Evaporation at t ~ 10^{-5} s -- BEFORE BBN (t_BBN ~ 1 s). The PBHs
evaporate into radiation before nucleosynthesis. They leave no relic.

For PBHs to survive to today: need M > 10^{15} g.

```
10^{15} g ~ 10^{38} GeV
M_Pl^2 / m_T > 10^{38} GeV
m_T < M_Pl^2 / 10^{38} GeV ~ 10^{38} / 10^{38} ~ 1 GeV
```

But at m_T ~ 1 GeV, the PGT bounce scale is:

```
rho_crit ~ m_T^2 M_Pl^2 ~ (1 GeV)^2 (10^{19} GeV)^2 ~ 10^{38} GeV^4
T_bounce ~ 10^{9.5} GeV
```

This is above the QCD scale and the bounce COULD produce PBHs at
10^{15} g. However:

1. The power spectrum at k ~ m_T must have delta > delta_c ~ 0.45
   for PBH formation. Branch K showed T(k) ~ O(1) at k ~ k_b --
   oscillatory but NOT enhanced. No amplification mechanism exists
   in the minimal model.

2. Even if PBHs form, the FRACTION depends on the pre-bounce power
   spectrum at k ~ m_T, which is an initial condition the model does
   not specify.

3. The PBH mass spectrum, abundance, and constraints depend on the
   pre-bounce perturbation amplitude at ONE specific scale, which is
   completely unconstrained.

### Verdict

**ECH: Planck-mass PBHs evaporate instantly. PGT: marginal survival
possible for m_T ~ 1 GeV, but requires fine-tuned pre-bounce
perturbation amplitude that the model does not predict.
FAIL_NO_PREDICTIVE_YIELD.**
