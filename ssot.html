How to work this queue

  1. Pick the lowest-ID P0 task whose dependencies are met.
  2. Flip status to [~] in project-context/SSOT/queue.md when you start.
  3. When done, flip to [x] and move the row to the Completed section with the commit hash.
  4. If blocked, flip to [!] with a one-line reason.
  5. When adding new tasks: insert at correct priority; ID them P{paper}-{slug} or P-{program-slug}.
  6. Never delete a completed task row. That's the record.
  7. Update this viewer (ssot.html) in the same commit as any status / queue change so the site doesn't drift from the canonical SSOT.
